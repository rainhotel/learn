# 中大厂暑期求职准备完整大纲

## 总体周期

以 2026-07-13 为起点执行 8 周。每周必须产出可检查的成果，不以“看完课程”作为完成标准。

## Week 1：定位、证据与基线

- 收集 15-20 个目标岗位 JD，提取重复能力词。
- 确定主线为 `Java 后端 + AI Agent 工程`，保留 Java 后端版和 Agent 工程版两个变体。
- 建立简历证据台账：经历、职责、难点、方案、结果、代码/文档证据、保密边界。
- 完成 Java 基线：线程状态、JMM、synchronized、volatile、CAS、线程池、CompletableFuture。
- 输出 Agent 项目一页设计和 MVP 验收标准。

验收：能用 90 秒完成自我介绍；能指出简历中所有需要核实的数字；项目范围不超过 4 个核心模块。

## Week 2：Java 并发原理与实验

- JMM、happens-before、可见性、原子性、有序性。
- synchronized 锁升级与 Monitor；ReentrantLock、AQS、Condition。
- volatile、CAS、ABA、LongAdder、并发容器。
- 用 JMH 或可重复实验验证竞争、伪共享、锁与原子操作差异。
- 项目实现任务状态机、执行器接口和单机异步执行。

验收：至少 6 个最小实验；能画出一个任务从提交到完成的线程与状态变化。

## Week 3：线程池、异步编排与背压

- ThreadPoolExecutor 参数、拒绝策略、队列选择、任务隔离。
- CompletableFuture 异常传播、超时、组合和线程池污染。
- 虚拟线程适用边界；CPU 密集与 I/O 密集任务区别。
- 项目加入有界队列、并发配额、超时、取消、重试和背压。
- 回头强化微信公众号项目的并发叙事与证据。

验收：给出线程池参数推导；通过压测展示无背压与有背压的区别。

## Week 4：数据库、缓存与一致性

- MySQL 索引、事务隔离、MVCC、锁、慢查询分析。
- Redis 数据结构、缓存模式、击穿/穿透/雪崩、分布式锁边界。
- 幂等键、Outbox、任务恢复、至少一次与至多一次语义。
- 项目持久化运行记录、步骤事件和幂等状态，支持进程重启恢复。

验收：做一次故障注入；重启后任务不丢失、不重复产生不可接受副作用。

## Week 5：Agent Runtime 核心

- Agent loop、tool calling、上下文组装、短期/长期记忆、检查点。
- 工具 schema、权限、超时、错误分类和可观测性。
- 项目实现 Planner/Executor、工具注册、上下文预算和执行轨迹。
- 对照 Xpert 实习经验，整理 Memory 或插件运行时的一个深度故事。

验收：完成一个多步骤任务；每一步有输入、输出、耗时、错误和状态记录。

## Week 6：可靠性、安全与可观测性

- 限流、熔断、重试、超时、隔离、补偿；识别重试风暴。
- Prompt injection、工具越权、敏感数据和人工审批边界。
- 日志、指标、trace、成本与 token 统计。
- 项目加入策略校验、危险工具审批、失败分类和运行看板。

验收：准备 5 类故障场景，展示系统如何降级和恢复。

## Week 7：简历定稿与面试表达

- 将主简历压缩至两页以内，删除重复的“个人优势”。
- Agent 实习保留 3-4 个最强模块，每条突出个人动作、工程难点和结果。
- 形成 Java 后端版、Agent 工程版两个定制版本。
- 整理 3 个项目故事，每个包含背景、约束、方案、取舍、结果、复盘。
- 完成两轮模拟面试和录音复盘。

验收：任何简历技术词都能连续回答三层追问；自我介绍控制在 90 秒。

## Week 8：作品集、投递与迭代

- 项目 README、架构图、演示脚本、压测报告和关键决策记录完整。
- 建立目标公司分层和投递表，按岗位定制前 1/3 内容。
- 每次面试后更新问题库和薄弱项，不临时推翻整套计划。
- 对暑期成果做一次阶段复盘，决定下一阶段偏 Java 深度还是 Agent 平台深度。

验收：可以在 5 分钟内演示项目，在 15 分钟内完成架构答辩。

## 贯穿全程的算法最低配

- 每周 4-6 题，覆盖数组/链表、二叉树、图、二分、滑窗、堆、回溯、动态规划。
- 每题记录方法、复杂度、边界和错误原因，不追求题量虚高。
- Week 5 起每周做一次 45 分钟限时模拟。

## 暑期退出标准

- 简历不是术语清单，而是可信的工程成果说明。
- Java 并发问题能从原理、代码、参数和生产风险四层回答。
- Agent 项目能说明运行时模型、可靠性、安全和取舍。
- 至少有一个项目具备运行数据、故障实验和架构决策记录。
