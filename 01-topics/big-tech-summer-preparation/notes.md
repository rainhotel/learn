# 简历诊断与修改原则

## 当前版本的关键判断

### 应保留并强化

- Xpert Agent 平台实习是首要卖点，应占最大篇幅。
- 微信公众号系统适合承载 Java 并发和可靠性故事。
- CampusBites 适合证明从 0 到 1、微信生态接入和真实用户交付。
- GPA 3.96、四六级和竞赛可以简洁保留。

### 应压缩或调整

- 三页压缩为两页；第三页只有资格证书，版式利用率明显不合理。
- “个人优势”与实习、技能内容重复，优先删除或改成顶部 2 行摘要。
- “掌握技能”改为分层技能：Java/后端、数据与中间件、Agent 工程、工程工具。
- Agent 实习从 7 个密集模块压缩到 3-4 个最强故事，其余在面试中展开。
- 日期格式统一；教育经历的入学日期需要确认是否应为 2024-09，而不是 2024-01。
- 中英文、空格和大小写统一：Spring Boot、TypeScript、PostgreSQL、File-backed Memory 等。

## 每条经历的写法

推荐结构：在什么约束下，负责什么关键动作，采用什么方案，解决什么问题，结果如何验证。

避免：只列模块名、堆砌框架、使用无法解释的宏大表述、将团队成果全部写成个人成果。

## 需要核实的证据

- `60w+ 行`的统计口径和必要性。
- 微信公众号系统的真实批次、时延、失败率和运行规模。
- 大烨实习中 `25%`、`20%`、`日均 2 万条`的来源。
- CampusBites `累计用户超 1000`的统计口径。
- “为多家公司提供落地软件解决方案”的具体数量、角色和可公开案例。

## 推荐简历结构

1. 姓名、联系方式、GitHub/博客。
2. 教育经历与一句话定位。
3. 实习经历。
4. 项目经历。
5. 技能与荣誉。

## 两个岗位版本

### Agent 工程版

强调 Runtime、Memory、插件、Tool Calling、身份接入、任务编排和大型代码库协作。

### Java 后端版

强调 Java 21、并发、数据库、缓存、异步任务、幂等、重试、限流和可观测性；Agent 经历作为差异化业务背景。
