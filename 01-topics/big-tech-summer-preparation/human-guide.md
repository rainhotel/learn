# 暑期行动导学页

## 为什么重要

你现在最有价值的资产不是“会用很多框架”，而是已经进入过真实企业级 Agent 平台代码库，并承担过运行时、插件、身份和外部接入工作。暑假的关键不是再堆一批名词，而是把这份稀缺经历转化为面试官能快速理解、相信并继续追问的工程能力。

## 当前阶段

当前处于定位和基线阶段。先明确目标岗位、梳理证据、诊断基础，再开始项目建设和简历压缩。简历修改不是最后一周的排版任务，而是贯穿整个暑假的成果提炼过程。

## 四条工作流

1. 简历：从经历清单变成证据清晰的两页简历。
2. Java：从“用过 Spring Boot”提升到能解释运行机制、并发取舍和故障处理。
3. Agent：做一个能展示运行时设计而非简单聊天 UI 的项目。
4. 面试：把每周学习成果转为口述、实验、指标和追问答案。

## 时间分配

建议每周投入 25-30 小时。根据 2026-07-13 岗位采样调整为：

- Java、传统后端与系统设计：10-12 小时
- Agent Runtime 项目：8-10 小时
- 算法：4 小时
- 前端闭环、自动化测试、简历与口述：3-4 小时

如果时间不足，优先顺序是：可验证项目 > Java 核心基础 > 简历证据 > 扩展功能。

## 每周固定节奏

- 周一：确定本周一个可验收目标。
- 周二至周四：学习一个机制，同时写最小实验并推进项目。
- 周五：压测、故障注入或代码复盘。
- 周六：整理简历素材，做一次 30 分钟项目口述。
- 周日：复盘并裁剪下周范围。

## 最值得反复检查的原则

- 不写无法解释或无法举证的数据。
- 每个技术点都要能回答：为什么用、替代方案是什么、失败时怎么办。
- 项目每增加一个组件，都必须对应一个真实问题。
- 用 Agent 项目连接 Java 并发和后端工程，避免三条学习线互相割裂。

## 现在做什么

第一周只完成三件事：证据台账、Java 基线、项目 MVP 设计。不要立即重写简历，也不要先搭一个庞大的微服务脚手架。
