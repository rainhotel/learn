# 中大厂暑期求职准备

## Goal

- 在 2026 年暑假形成清晰的求职定位：`Java 后端 + AI Agent 工程`。
- 把现有经历从“做过很多模块”整理为“有深度、可验证、能经受追问”的证据链。
- 完成一版两页以内的主简历，并能针对 Java 后端、AI 应用/Agent 两类岗位定制。
- 用一个 Java Agent 工程项目同时补强 Agent、并发、可靠性和传统后端能力。

## Scope

包含：简历改造、Java 并发与后端基础、Agent 项目、项目复盘、面试表达和投递准备。

暂不包含：大规模刷算法竞赛题、为了堆技术栈而重写所有旧项目、缺少证据的经历包装。

## Outcome

- 1 份两页主简历，2 份岗位定制版。
- 1 个可运行、可压测、可演示、可讲解的 Java Agent Runtime 项目。
- 30 个 Java/并发核心问题的口述与实验记录。
- 3 段重点经历的 STAR/问题-方案-权衡-结果故事库。
- 1 套项目演示、架构图、指标和面试追问清单。

## Status

- 阶段：Phase 0 - 定位与基线
- 优先级：High
- 最近一次更新：2026-07-13
- 当前学习模式：完整大纲驱动

## Resume Baseline

当前优势：

- Xpert 企业级 Agent 平台实习经历稀缺，覆盖 Memory、插件运行时、编程代理、IM 接入和身份系统。
- 有真实交付项目、线上用户和企业场景，不是纯课程项目。
- GPA、英语和竞赛成绩能通过基础筛选。

当前缺口：

- 简历三页，第三页几乎空白；信息层级和篇幅控制需要重做。
- Agent 实习条目过多且术语密集，个人职责、难点、取舍和结果证据不够突出。
- “掌握技能”缺乏分层，Java 基础、并发、数据库、网络和工程能力没有形成可信能力面。
- 并发项目目前主要是 API 并行化描述，需要补上线程池参数、背压、超时、幂等、恢复和压测证据。
- 两段实习和两个项目之间缺少统一叙事。

## Positioning

主定位：有企业级 Agent 平台经验的 Java/服务端后端候选人。

一句话版本：能做传统后端的可靠性与并发工程，也能建设 Agent Runtime、工具、记忆和插件，并借助 AI 完成前后端闭环交付。

岗位市场依据见：`../../06-research/agent-backend-job-market/`。
