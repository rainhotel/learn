## 摘要

本课程设计围绕混合噪声图像增强和未知降质图像复原两个任务展开。图像增强任务中，待处理图像同时含有随机噪声和周期噪声。本文先通过傅里叶频谱分析定位周期噪声峰值，再设计高斯陷波滤波器在频率域抑制周期噪声，随后使用中值滤波、均值滤波、高提升锐化和百分位灰度拉伸在空间域进一步降低随机噪声并改善视觉质量。图像复原任务中，默认按学号尾数为偶数选择图 1 模糊树林图像，采用近似高斯点扩散函数的维纳复原方法，并结合高提升锐化和灰度拉伸恢复边缘细节。实验结果表明，增强任务的 MSE 由 0.071191 降至 0.006541，SNR 由 4.664 dB 提升至 15.032 dB，PSNR 由 11.476 dB 提升至 21.844 dB，SSIM 由 0.1039 提升至 0.6558。图像复原任务中，图 1 的平均梯度由 0.03489 提升至 0.11841，拉普拉斯方差由 0.01926 提升至 0.12463，说明复原后边缘与细节清晰度明显增强。

## 1. 任务描述

本课程设计包括两个部分。

第一部分是图像增强算法设计。已知待处理图像中的噪声由随机噪声和周期噪声混合组成，要求设计一套空间域与频率域结合的图像增强算法，处理带噪声图像，去除噪声并提高图像质量。清晰图像只作为算法评估使用。评价指标包括均方误差、信噪比和结构相似度等。

第二部分是图像复原算法设计。题目给出两幅降质图像，要求根据学号尾数二选一进行复原。本文默认按偶数学号选择图 1 模糊树林图像。由于题目未提供复原任务的清晰参考图，因此复原部分采用信息熵、灰度标准差、平均梯度和拉普拉斯方差等无参考指标评价复原效果。

## 2. 问题分析

### 2.1 图像增强任务

观察 `dogDistorted.bmp` 可知，图像中存在明显的规则条纹，同时还包含随机噪声。规则条纹在空间域中表现为周期性明暗变化，在频率域中对应远离频谱中心的亮点。因此，单纯使用中值滤波或均值滤波会削弱随机噪声，但难以彻底消除周期噪声；单纯使用频域陷波可以抑制周期噪声，但对随机噪声处理不足。基于这一特点，本文采用频域和空间域结合的处理流程。

傅里叶频谱分析发现，周期噪声主峰主要位于频谱中心左右约 71 像素、上下约 74 像素的位置，因此选取 `(0, ±71)` 和 `(±74, 0)` 作为主要陷波中心。

### 2.2 图像复原任务

图 1 模糊树林图像的主要退化表现为整体边缘不清晰、纹理细节弱。该类问题可近似看作清晰图像经过低通型点扩散函数模糊并叠加少量噪声：

```text
g(x, y) = h(x, y) * f(x, y) + n(x, y)
```

其中 `f(x, y)` 为原始图像，`h(x, y)` 为退化函数，`n(x, y)` 为噪声。由于真实退化函数未知，本文用高斯点扩散函数近似模糊过程，并采用维纳滤波进行频域复原。维纳滤波相比直接逆滤波更稳定，可以在增强高频细节的同时抑制噪声放大。

## 3. 算法设计

### 3.1 混合噪声图像增强算法

整体流程如下：

1. 读入退化图像和清晰参考图像，并转换为 `[0, 1]` 范围的灰度图。
2. 对退化图像进行傅里叶变换，观察频谱中的周期噪声峰值。
3. 根据峰值位置构造高斯陷波滤波器，抑制周期噪声。
4. 对频域滤波结果进行 `5 x 5` 中值滤波，去除随机脉冲噪声。
5. 使用 `3 x 3` 均值滤波进一步平滑残余噪声。
6. 使用高提升锐化补偿平滑造成的细节损失。
7. 使用百分位灰度拉伸改善整体对比度。
8. 与清晰参考图计算 MSE、SNR、PSNR 和 SSIM。

高斯陷波滤波器定义为：

```text
H_k(u, v) = 1 - exp(-D_k(u, v)^2 / (2D0^2))
H(u, v) = product(H_k(u, v))
```

其中 `D_k(u, v)` 表示频率点 `(u, v)` 到第 `k` 个噪声峰中心的距离，`D0` 为陷波半径。本文取 `D0 = 10`。

高提升锐化公式为：

```text
g(x, y) = f(x, y) + alpha * (f(x, y) - f_smooth(x, y))
```

本文取 `alpha = 0.15`。

### 3.2 模糊图像复原算法

图 1 复原流程如下：

1. 读入彩色降质图像，并提取亮度分量。
2. 使用高斯点扩散函数近似退化模型，参数为 `psf_size = 13`、`psf_sigma = 1.35`。
3. 在频率域使用维纳滤波进行复原，参数 `K = 0.004`。
4. 将复原亮度与原亮度按比例融合，避免过度复原产生振铃。
5. 使用高提升锐化增强细节。
6. 使用百分位拉伸改善对比度。
7. 将处理后的亮度分量替换回彩色图像。
8. 使用无参考指标评价复原前后变化。

维纳滤波公式为：

```text
F_hat(u, v) = H*(u, v) / (|H(u, v)|^2 + K) * G(u, v)
```

其中 `G(u, v)` 为退化图像频谱，`H(u, v)` 为退化函数频谱，`H*(u, v)` 为其共轭，`K` 为噪声功率与信号功率比的近似参数。

## 4. 评价指标

增强任务使用有参考评价指标。

均方误差：

```text
MSE = (1 / MN) * sum((f(x, y) - g(x, y))^2)
```

信噪比：

```text
SNR = 10 * log10(sum(f(x, y)^2) / sum((f(x, y) - g(x, y))^2))
```

峰值信噪比：

```text
PSNR = 10 * log10(1 / MSE)
```

结构相似度 SSIM 综合亮度、对比度和结构差异衡量图像相似程度，本文在 MATLAB 中使用局部高斯窗口手写实现。

复原任务没有清晰参考图，因此使用无参考指标。

信息熵反映灰度信息量。灰度标准差反映整体对比度。平均梯度反映边缘变化强度。拉普拉斯方差反映高频细节和清晰度。


## 7. 结论

本文完成了图像增强与图像复原两个任务。增强任务针对随机噪声和周期噪声混合退化的特点，将频率域高斯陷波和空间域滤波结合使用，能够同时抑制周期条纹和随机噪声。实验结果显示，处理后 MSE 大幅下降，SNR、PSNR 和 SSIM 均明显提升，说明算法具有较好的增强效果。

复原任务中，本文针对图 1 模糊树林图像建立近似高斯模糊退化模型，并采用维纳滤波进行复原。由于缺少清晰参考图，本文使用无参考指标进行评价。结果表明，复原后图像的信息熵、标准差、平均梯度和拉普拉斯方差均有所提升，说明图像细节和边缘清晰度得到改善。

本实验也存在一定限制。增强任务中的陷波中心是根据当前图像频谱人工选取的，若换用其他周期噪声图像，需要重新分析频谱峰值。复原任务中的退化函数为近似估计，并非真实成像退化模型，因此可能存在局部过锐化或振铃现象。后续可进一步研究自适应峰值检测、盲去卷积和更稳定的无参考图像质量评价方法。
