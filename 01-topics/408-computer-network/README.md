# 408 计算机网络

## Goal

- 以 408 统考要求为边界，系统拿下计算机网络模块。
- 不只存笔记，而是形成“知识大纲 + 高频题型 + 公式速查 + 错题归档”的复习系统。
- 最终达到：选择题稳定、综合题会拆、计算题写得出公式和边界条件。

## Scope

- 按 408 常见范围学习：体系结构、物理层、数据链路层、网络层、运输层、应用层。
- 参考王道常见章节体系和历年真题高频题型，整理考点、题型和解法。
- 重点覆盖：时延、奈奎斯特/香农、CRC、滑动窗口、CSMA/CD、以太网、IP 编址、CIDR、分片、路由、TCP 序号确认号、连接管理、流量控制、拥塞控制、应用层协议与端口。

## Non-Scope

- 不复刻王道或真题原文，只做知识点、考法和解题模板整理。
- 不以工程部署和厂商配置为主线。
- 不展开超纲前沿网络技术，先保证 408 得分效率。

## Outcome

- 能默写五层模型、每层职责、代表协议和 PDU 名称。
- 能稳定完成子网划分、路由聚合、最长前缀匹配、IP 分片题。
- 能解释并计算 TCP 序号、确认号、握手挥手、窗口和拥塞控制。
- 能把综合题拆成“链路层转发 + 网络层路由 + 运输层/TCP + 应用层过程”。
