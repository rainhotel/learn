## Error Patterns

  - 把传播时延和发送时延混淆
  - 分片计算时忽略首部长度
  - TCP 确认号理解错误
- 最近最容易混淆的概念：

## Answered Questions

### 为什么 408 网络要优先抓网络层和运输层？

- 结论：因为它们既覆盖大量选择题，也经常进入综合题，投入产出比最高。
- 依据：近年公开的 408 题型分析普遍指出网络综合题常落在数据链路层、网络层、运输层。
- 例子：IP 编址、分片、TCP 握手/窗口调整都是典型高频点。

### 为什么 GBN 和 SR 的窗口上界不同？

- 结论：因为 GBN 用累计确认，接收方窗口为 1；而 SR 要对失序帧单独缓存和确认，为避免新旧帧混淆，窗口不能超过序号空间一半。
- 依据：GBN 与 SR 的确认机制和接收策略不同。
- 例子：同样是 `k` 位序号，GBN 发送窗口最大可到 `2^k - 1`，SR 只能到 `2^(k-1)`。

## 高频易混问答补充（2026-06-20）

### 为什么综合题优先抓数据链路层、网络层、运输层？

- 结论：这三层既有稳定计算题，也最容易跨层组合成综合题。
- 数据链路层提供帧、MAC、交换机、窗口与介质访问控制。
- 网络层提供 IP 地址、路由、分片、ARP/NAT/ICMP。
- 运输层提供 TCP 序号确认号、连接管理、流量控制与拥塞控制。
- 做综合题时常见链路是：先判断局域网转发，再判断 IP 路由，再判断 TCP 或应用过程。

### 子网划分为什么总是错在边界？

- 结论：因为题目考的不只是公式，而是网络地址、广播地址、可用范围和前缀边界。
- 做题顺序应固定为：确定前缀长度、算块大小、列网络地址、列广播地址、检查主机数量。
- 常见错误是只算 `2^h`，忘记可用主机通常要减 2。

### IP 分片为什么偏移量要除以 8？

- 结论：IPv4 首部中的片偏移字段以 8 字节为单位。
- 因此偏移量不是字节号本身，而是“该片数据起始字节号 / 8”。
- 除最后一片外，每片数据长度也通常要取 8 字节整数倍，否则下一片偏移会不合法。

### 为什么 TCP 的确认号不是“最后收到的字节号”？

- 结论：TCP 确认号表示接收方期望收到的下一个字节序号。
- 如果收到从 100 开始的 200 字节数据，那么确认号是 300，而不是 299。
- 这能自然表达累计确认：ACK=300 表示 300 之前的数据都已经收到了。

### 流量控制和拥塞控制怎么一眼区分？

- 结论：流量控制保护接收方，拥塞控制保护网络。
- 流量控制看 `rwnd`，由接收方通告。
- 拥塞控制看 `cwnd`，由发送方根据网络拥塞情况调整。
- 发送端真正能发多少，常受 `min(rwnd, cwnd)` 限制。

### DNS、ARP、DHCP 三个“解析/分配”怎么区分？

- DNS：域名到 IP 地址。
- ARP：IP 地址到 MAC 地址。
- DHCP：给主机分配 IP、掩码、网关、DNS 等网络配置。
- 口诀：DNS 找 IP，ARP 找 MAC，DHCP 发配置。
