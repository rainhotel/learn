# 408 计算机网络知识点大纲

## 使用方式

- 这份大纲按 408 常见命题范围、王道复习章节顺序和历年真题高频题型组织。
- 目标不是复刻教材或真题题干，而是整理“考什么、怎么考、先学什么、错在哪里”。
- 第一轮按章节走；第二轮按题型走；冲刺阶段按易错点和公式表走。

## 0. 考试定位总览

### 0.1 分值与题型

- 计算机网络通常是 408 中分值较小但稳定的模块，常见约 25 分。
- 常见结构：选择题覆盖全章，综合题多落在数据链路层、网络层、运输层，且常跨层。
- 命题风格：
  - 概念辨析：协议、服务、接口、设备层次、协议功能。
  - 过程判断：交换机学习、ARP、DHCP、DNS、TCP 握手挥手。
  - 公式计算：时延、码元率、CRC、窗口利用率、子网划分、IP 分片、TCP 窗口。
  - 综合分析：拓扑 + 地址 + 路由 + TCP/应用过程。

### 0.2 优先级

| 优先级 | 章节 | 原因 |
| --- | --- | --- |
| S | 网络层 | 子网划分、CIDR、路由、分片、ARP/NAT/ICMP 都高频，综合题常客 |
| S | 运输层 | TCP 序号确认号、连接管理、流量控制、拥塞控制常考 |
| A | 数据链路层 | CRC、滑动窗口、CSMA/CD、以太网、交换机、VLAN 都容易出题 |
| B | 体系结构与性能指标 | 选择题基础，时延计算会影响后续题 |
| B | 应用层 | 多为协议功能、端口、过程排序，性价比高 |
| C | 物理层 | 计算点集中，范围相对固定，重在不混公式 |

### 0.3 第一轮学习顺序

1. 体系结构与性能指标：建立分层地图。
2. 数据链路层：先拿下滑动窗口、CRC、CSMA/CD。
3. 网络层：集中训练地址、路由、分片。
4. 运输层：集中训练 TCP 过程和窗口。
5. 应用层：背协议功能、端口和典型流程。
6. 物理层：最后统一刷公式和概念题。

## 1. 体系结构与性能指标

### 1.1 网络基本概念

- 计算机网络、互联网、互连网、Internet 的区别。
- 边缘部分与核心部分。
- 主机、路由器、交换机、链路、ISP。
- 客户/服务器方式与 P2P 方式。
- 资源子网与通信子网。

### 1.2 交换方式

- 电路交换：
  - 建立连接、独占资源、适合连续实时通信。
  - 缺点是线路利用率可能低。
- 报文交换：
  - 存储转发，报文整体作为转发单位。
  - 缺点是缓存压力大、时延不稳定。
- 分组交换：
  - 把报文切成分组，存储转发。
  - 高频比较：分组交换为什么适合计算机通信。
- 数据报方式与虚电路方式：
  - 数据报：每个分组独立选路，不保证顺序。
  - 虚电路：先建立逻辑连接，分组沿同一路径。

### 1.3 分层体系结构

- 协议、服务、接口：
  - 协议是同层实体之间的水平规则。
  - 服务是下层向上层提供的垂直功能。
  - 接口是相邻层交互的边界。
- OSI 七层：应用层、表示层、会话层、运输层、网络层、数据链路层、物理层。
- TCP/IP 四层：应用层、运输层、网际层、网络接口层。
- 五层教学模型：应用层、运输层、网络层、数据链路层、物理层。
- PDU 名称：应用层报文、运输层报文段/用户数据报、网络层数据报/分组、链路层帧、物理层比特流。
- 封装与解封装：发送端自上而下加首部，接收端自下而上去首部。

### 1.4 性能指标

- 速率、带宽、吞吐量：带宽是能力上限，吞吐量是实际完成量。
- 发送时延：`发送时延 = 数据长度 / 发送速率`，看数据长度和链路速率，不看距离。
- 传播时延：`传播时延 = 链路长度 / 信号传播速率`，看距离和传播速度，不看数据长度。
- 处理时延、排队时延、总时延。
- RTT：往返时间，常用于 TCP、停等协议和窗口利用率题。
- 时延带宽积：`时延带宽积 = 带宽 × 传播时延`，表示链路中“在途”的比特量。

### 1.5 高频题型

- 判断协议、服务、接口的关系。
- 给出链路速率、距离、帧长，计算发送时延、传播时延、总时延。
- 比较电路交换、报文交换、分组交换的优缺点。
- 判断 OSI/TCP-IP/五层模型的层次对应。

### 1.6 易错点

- 把发送时延和传播时延混为一谈。
- 把协议说成“上下层之间的规则”。
- 把带宽等同于吞吐量。
- 只背 OSI 七层，不会映射到 TCP/IP 和五层模型。

## 2. 物理层

### 2.1 物理层任务

- 在传输媒体上传输比特流。
- 规定机械特性、电气特性、功能特性、过程特性。
- 关注信号、接口、介质、传输速率，不负责帧和地址。

### 2.2 数据、信号与传输方式

- 模拟数据、数字数据。
- 模拟信号、数字信号。
- 基带传输与宽带传输。
- 单工、半双工、全双工。
- 串行传输与并行传输。
- 同步传输与异步传输。

### 2.3 编码与调制

- 常见数字编码：不归零编码、曼彻斯特编码、差分曼彻斯特编码。
- 曼彻斯特编码常见特点：每比特中间跳变，可携带同步信息。
- 数字数据调制为模拟信号：ASK、FSK、PSK、QAM。
- 码元、比特、波特率、比特率：一个码元携带 `log2 V` 位信息时，`比特率 = 波特率 × log2 V`。

### 2.4 奈奎斯特定理与香农定理

- 奈奎斯特定理：理想低通信道最大码元率为 `2W Baud`。
- 若每个码元有 `V` 种离散状态，则最大数据率为 `2W log2 V`。
- 香农定理：有噪声信道极限信息传输速率为 `C = W log2(1 + S/N)`。
- 信噪比如果用 dB 表示：`S/N(dB) = 10 log10(S/N)`。
- 题型入口：无噪声、理想低通、问码元率，优先奈奎斯特；有噪声、给信噪比、问极限速率，优先香农。

### 2.5 传输介质

- 导向传输介质：双绞线、同轴电缆、光纤。
- 非导向传输介质：无线电、微波、红外线、卫星通信。
- 光纤：抗电磁干扰强、带宽大、衰减小。
- 多模光纤与单模光纤特点。

### 2.6 信道复用

- 频分复用 FDM。
- 时分复用 TDM。
- 波分复用 WDM。
- 码分复用 CDM/CDMA：码片序列正交，解码用内积判断某站点发送 1、0 或未发送。

### 2.7 物理层设备

- 中继器：放大、整形、再生信号，不识别帧、MAC 地址和 IP 地址。
- 集线器：多端口中继器，所有端口共享带宽，不能分割冲突域，不能分割广播域。

### 2.8 高频题型

- 奈奎斯特/香农计算。
- 波特率与比特率换算。
- CDMA 内积解码。
- 判断设备工作层次。
- 判断双绞线、同轴、光纤、无线介质特点。

### 2.9 易错点

- 把奈奎斯特当成有噪声信道公式。
- 信噪比 dB 没有先换成普通比值。
- 把 Hub 当成能按地址转发的设备。
- 曼彻斯特编码中“比特中间跳变”的含义记反。

## 3. 数据链路层

### 3.1 数据链路层任务

- 为同一链路相邻节点提供帧传输。
- 核心功能：封装成帧、透明传输、差错检测、流量控制、介质访问控制。

### 3.2 封装成帧与透明传输

- 成帧方法：字符计数法、字节填充法、零比特填充法、违规编码法。
- HDLC 零比特填充：数据字段中每出现连续 5 个 1，就插入 1 个 0。
- 标志字段通常是 `01111110`。

### 3.3 差错控制

- 奇偶校验：简单检错，不能可靠纠错。
- CRC 循环冗余检验：生成多项式阶数为 r，则数据后补 r 个 0；模 2 除法得到 r 位余数；CRC 是检错，不是纠错。
- 海明码：用校验位定位并纠正单比特错误；常见要求是校验位数 r 满足 `2^r >= m + r + 1`。

### 3.4 流量控制与可靠传输

- 停止-等待协议：发一帧，等确认，再发下一帧，利用率低但机制简单。
- GBN：发送方可连续发多个帧；接收窗口为 1；累计确认；超时后从最早未确认帧开始全部重传；n 位序号时发送窗口 `W_T <= 2^n - 1`。
- SR：接收方可缓存失序帧；单帧确认，单帧重传；n 位序号时发送窗口和接收窗口通常都不超过 `2^(n-1)`。
- 通用约束：为避免新旧帧混淆，常用 `W_T + W_R <= 2^n`。

### 3.5 窗口协议效率

- 停等利用率：`U = Td / (Td + 2Tp + Tack)`。
- 滑动窗口利用率：`U = min(1, W × Td / (Td + 2Tp + Tack))`。
- 满利用率判定：`W × Td >= Td + 2Tp + Tack`。
- 高频步骤：先算数据帧发送时延 `Td`，再算第一帧确认返回周期，再用窗口覆盖等待周期。

### 3.6 介质访问控制

- 信道划分：FDMA、TDMA、WDMA、CDMA，原则上通过预分配资源避免冲突。
- 随机访问：ALOHA、时隙 ALOHA、CSMA、CSMA/CD、CSMA/CA。
- CSMA 三种坚持策略：1-坚持空闲立即发送；非坚持忙则随机等待；p-坚持空闲时以概率 p 发送。
- CSMA/CD：先听后发，边发边听，冲突停止，随机退避。
- CSMA/CD 最小帧长约束：`帧发送时延 >= 2 × 单程传播时延`。
- 二进制指数退避：第 i 次冲突后 `k = min(i, 10)`，随机选 `0 ~ 2^k - 1`。
- CSMA/CA：无线局域网常用，强调避免冲突，通过 ACK 确认正确接收，可涉及 RTS/CTS、NAV、帧间间隔。

### 3.7 局域网与以太网

- 以太网 MAC 服务：无连接、不可靠服务。
- MAC 地址：链路层地址，也称以太网地址、硬件地址，通常 48 位。
- 以太网帧：目的地址、源地址、类型、数据、FCS。
- 最小帧长 64B 常与 CSMA/CD 约束相关。
- 以太网命名：如 `100BaseT` 表示 100Mbps、基带传输、双绞线。
- IEEE 802：主要覆盖物理层和数据链路层，数据链路层可分 LLC 与 MAC。
- 802.11：常考 CSMA/CA、确认机制、无线冲突检测困难。

### 3.8 交换机、网桥、VLAN

- 网桥：数据链路层设备，按 MAC 地址转发帧，可以分割冲突域，默认不分割广播域。
- 交换机：多端口网桥，每个端口通常是独立冲突域，默认整个交换网络仍是一个广播域。
- 交换机自学习：从源 MAC 学习端口；查目的 MAC 决定转发、过滤或泛洪。
- VLAN：基于交换机的逻辑分组，可划分广播域；802.1Q 标签常用于 trunk 链路。

### 3.9 PPP 与 HDLC

- PPP：点对点链路协议；面向字节；支持多种网络层协议；不提供可靠传输，不使用序号和确认来保证可靠。
- HDLC：面向比特，常考零比特填充和帧格式。

### 3.10 高频题型

- CRC 模 2 除法。
- HDLC 零比特填充。
- GBN/SR 窗口上界、重传数量、序号位数。
- 停等与滑动窗口利用率。
- CSMA/CD 最小帧长、最大距离、退避范围。
- Hub/Switch/Router 冲突域和广播域数量。
- 交换机 MAC 地址表学习与转发。

### 3.11 易错点

- GBN 的确认是累计确认，SR 是选择确认。
- SR 窗口不能套 GBN 的 `2^n - 1`。
- CRC 用模 2 除法，不进位、不借位。
- CSMA/CD 是有线以太网碰撞检测，CSMA/CA 是无线避免碰撞。
- 交换机默认不能分割广播域，但能分割冲突域。

## 4. 网络层

### 4.1 网络层任务

- 实现主机到主机的分组交付。
- 核心功能：异构网络互连、路由选择、分组转发、拥塞相关控制思想。
- IP 提供无连接、尽最大努力交付服务。

### 4.2 IPv4 数据报

- 首部长度：单位为 4B，最小 20B，最大 60B。
- 总长度：首部 + 数据，单位为字节。
- 标识、标志、片偏移：用于分片与重组。
- TTL：每经过一个路由器减 1，防止分组无限循环。
- 协议字段：指明上层协议，如 TCP、UDP、ICMP。
- 首部校验和：只检验 IP 首部。
- 源 IP 地址、目的 IP 地址。

### 4.3 IPv4 地址与子网划分

- 分类地址：A、B、C 类地址范围与默认掩码。
- 特殊地址：网络地址、广播地址、环回地址、私有地址。
- 子网划分：借主机位作为子网号；`可用主机数 = 2^h - 2`。
- CIDR：无类域间路由，斜线记法如 `/24`，地址块大小由主机位决定。
- VLSM：可变长子网掩码，按需求分配不同大小子网。

### 4.4 路由转发与路由聚合

- 最长前缀匹配：多条路由都匹配时，选前缀最长的一条。
- 路由聚合：找共同前缀；聚合后地址块必须覆盖目标网络，且注意是否引入多余地址。
- 默认路由：`0.0.0.0/0`。
- 主机路由：`/32`，优先级通常最高。

### 4.5 IP 分片

- 触发条件：IP 数据报长度超过链路 MTU。
- 每片总长度不能超过 MTU。
- 每片数据部分通常要是 8B 的整数倍，最后一片除外。
- 片偏移量 = 该片数据起始位置 / 8。
- DF 表示不分片，MF 表示后面还有分片。
- 只在目的主机重组，中间路由器不重组。

### 4.6 网络层协议

- ARP：IP 地址到 MAC 地址的解析；同一局域网内广播请求、单播应答。
- ICMP：差错报告和询问；ping 使用 ICMP 回显请求/应答；traceroute 利用 TTL 和 ICMP 差错报文思想。
- DHCP：主机动态获取 IP、掩码、网关、DNS 等；典型流程 Discover、Offer、Request、ACK；基于 UDP 67/68。
- NAT：私有地址与公网地址转换；PAT/NAPT 通过端口复用公网地址。

### 4.7 路由算法与路由协议

- 静态路由与动态路由。
- RIP：距离向量协议，基于跳数，最大 15 跳，16 表示不可达，可能慢收敛和计数到无穷。
- OSPF：链路状态协议，洪泛链路状态信息，本地用 Dijkstra 算最短路。
- BGP：自治系统之间的外部网关协议，关注可达性和策略，不单纯追求最短路径。
- IGP 与 EGP 的区别。

### 4.8 IPv6

- 地址长度 128 位。
- 首部固定 40B，格式简化。
- 路由器不分片，源主机负责路径 MTU 发现。
- 不使用 IPv4 首部校验和。
- 支持单播、多播、任播。
- 过渡技术：双协议栈、隧道技术、协议转换。

### 4.9 高频题型

- 给 IP 和掩码，求网络地址、广播地址、可用主机范围。
- 给主机数量，反推子网掩码或前缀长度。
- CIDR 路由聚合。
- 路由表最长前缀匹配。
- IP 分片长度、片偏移、MF 标志。
- ARP/DHCP/ICMP/NAT 的功能与过程判断。
- RIP/OSPF/BGP 的协议类型、算法思想和适用范围。

### 4.10 易错点

- 主机数忘记减网络地址和广播地址。
- 把路由器转发依据说成 MAC 地址。
- 分片偏移忘记除以 8。
- 把 IP 首部长度和总长度单位混淆。
- 把 ARP 方向记反：ARP 是 IP 到 MAC。
- DHCP 虽然分配 IP，但从协议栈看常按应用层协议理解，基于 UDP 工作。

## 5. 运输层

### 5.1 运输层任务

- 实现进程到进程的逻辑通信。
- 复用与分用。
- 差错检测。
- 可靠传输、流量控制、拥塞控制主要由 TCP 提供。
- 端口号用于标识应用进程。

### 5.2 UDP

- 无连接、尽最大努力交付、面向报文。
- 首部开销小，8B。
- 支持一对一、一对多、多对一、多对多。
- UDP 首部字段：源端口、目的端口、长度、校验和。
- 适用场景：DNS、DHCP、实时音视频等。

### 5.3 TCP 基本特性

- 面向连接、可靠交付、全双工通信、面向字节流、点对点。
- TCP 首部字段：源端口、目的端口、序号、确认号、数据偏移、控制位、窗口、校验和、紧急指针、选项。
- 常见控制位：SYN、ACK、FIN、RST、PSH、URG。

### 5.4 TCP 可靠传输

- TCP 对字节编号，不是对报文段编号。
- 确认号表示期望收到的下一个字节序号。
- 累计确认：ACK 到 n，表示 n 之前的字节均已收到。
- 超时重传。
- 快重传：收到多个重复 ACK 后尽快重传缺失段。
- 校验和覆盖伪首部、TCP 首部和数据。

### 5.5 TCP 连接管理

- 三次握手：客户端 SYN；服务端 SYN+ACK；客户端 ACK。
- 为什么不是两次握手：防止已失效的连接请求报文段导致错误建立连接。
- 四次挥手：主动关闭方 FIN；被动关闭方 ACK；被动关闭方 FIN；主动关闭方 ACK。
- TIME_WAIT：保证最后一个 ACK 可重传；让本连接旧报文在网络中消失。

### 5.6 流量控制

- 目的：防止发送方把接收方缓存打爆。
- 接收方通过接收窗口 rwnd 告知可接收空间。
- 发送窗口受接收窗口和拥塞窗口共同限制，常记为 `发送窗口 = min(rwnd, cwnd)`。
- 零窗口与窗口探测。

### 5.7 拥塞控制

- 目的：防止过多数据注入网络导致拥塞。
- 慢开始：cwnd 从小开始，按 RTT 近似指数增长。
- 拥塞避免：cwnd 线性增长。
- 慢开始门限 ssthresh：cwnd 小于门限时慢开始，到达门限后拥塞避免。
- 超时：ssthresh 通常变为当前 cwnd 的一半，cwnd 重新置小，进入慢开始。
- 快重传与快恢复：多个重复 ACK 触发，ssthresh 减半，cwnd 调整后进入拥塞避免/快恢复。
- AIMD：加性增大、乘性减小。

### 5.8 高频题型

- UDP 与 TCP 特性比较。
- TCP 首部字段作用判断。
- 根据 seq、数据长度求 ACK。
- 三次握手/四次挥手的序号、确认号和状态。
- rwnd、cwnd、发送窗口关系。
- 根据慢开始、拥塞避免、超时、重复 ACK 推 cwnd 变化。
- 判断流量控制与拥塞控制的区别。

### 5.9 易错点

- TCP 确认号是“期望的下一个字节”，不是“最后收到的字节”。
- SYN 和 FIN 各占一个序号。
- UDP 不是完全“无校验”，它有校验和字段。
- 流量控制看接收方，拥塞控制看网络。
- cwnd 单位可能是 MSS，也可能是字节，题目要看清。

## 6. 应用层

### 6.1 应用层总览

- 应用层协议定义应用进程交换报文的格式和规则。
- 常考协议功能、端口号、基于 TCP 还是 UDP、典型交互流程。

### 6.2 DNS

- 功能：域名到 IP 地址的解析。
- 层次结构：根域名服务器、顶级域名服务器、权威域名服务器、本地域名服务器。
- 查询方式：递归查询、迭代查询。
- 传输：通常 UDP 53，区域传送或响应过大时可能用 TCP 53。

### 6.3 Web 与 HTTP

- HTTP 无状态，基于 TCP，默认端口 80；HTTPS 默认 443。
- 非持久连接与持久连接。
- 请求报文与响应报文基本结构。
- Cookie 用于在无状态 HTTP 上维护状态。
- Web 访问综合流程：DNS 解析、TCP 建立连接、HTTP 请求/响应、TCP 连接释放或复用。

### 6.4 电子邮件

- SMTP：发送邮件、服务器之间转发邮件，基于 TCP，常用端口 25。
- POP3：用户从邮件服务器读取邮件，基于 TCP，常用端口 110。
- IMAP：在线管理邮件，功能比 POP3 强，基于 TCP，常用端口 143。
- 高频比较：SMTP 是推，POP3/IMAP 是取。

### 6.5 FTP

- 基于 TCP。
- 控制连接默认端口 21，整个会话期间保持。
- 数据连接主动模式常涉及服务器端口 20，被动模式由服务器告知客户端临时端口。
- 高频：控制连接与数据连接分离。

### 6.6 DHCP

- 功能：动态分配 IP 地址和网络配置。
- 典型流程：Discover、Offer、Request、ACK。
- 基于 UDP，服务器端口 67，客户端端口 68。
- 常与广播、默认网关、租约一起考。

### 6.7 其他协议与端口

| 协议 | 作用 | 运输层 | 常见端口 |
| --- | --- | --- | --- |
| DNS | 域名解析 | UDP/TCP | 53 |
| HTTP | Web 访问 | TCP | 80 |
| HTTPS | 加密 Web | TCP | 443 |
| FTP 控制 | 文件传输控制 | TCP | 21 |
| FTP 数据 | 文件数据连接 | TCP | 20 或临时端口 |
| SMTP | 邮件发送 | TCP | 25 |
| POP3 | 邮件读取 | TCP | 110 |
| IMAP | 邮件管理 | TCP | 143 |
| DHCP | 动态地址配置 | UDP | 67/68 |
| SNMP | 网络管理 | UDP | 161/162 |
| Telnet | 远程登录 | TCP | 23 |
| SSH | 安全远程登录 | TCP | 22 |

### 6.8 高频题型

- 协议功能匹配。
- 常见端口号匹配。
- DNS 递归/迭代过程判断。
- HTTP 持久/非持久连接 RTT 计算。
- FTP 控制连接与数据连接辨析。
- DHCP 获取地址流程排序。
- 综合题中解释“从输入 URL 到收到网页”的跨层过程。

### 6.9 易错点

- DNS 解析得到 IP 地址，不是 MAC 地址。
- DHCP 分配 IP，但运行在 UDP 之上。
- SMTP 负责发信，POP3/IMAP 负责收信。
- HTTP 无状态不等于 TCP 无连接。
- FTP 有两个连接，不是一个连接传到底。

## 7. 真题型综合题整理模板

### 7.1 子网划分题

1. 读清地址块和前缀长度。
2. 判断需要多少子网或每个子网多少主机。
3. 确定主机位 h 和前缀长度。
4. 写出网络地址、广播地址、可用范围。
5. 检查是否越界、是否满足主机数量。

### 7.2 路由聚合题

1. 把多个网络地址转成二进制前缀。
2. 找最长公共前缀。
3. 写出聚合后的 CIDR 地址块。
4. 检查是否包含额外地址，题目是否允许。

### 7.3 最长前缀匹配题

1. 将目的 IP 与各路由项掩码相与。
2. 找所有匹配项。
3. 选择前缀最长者。
4. 若无匹配项，看是否有默认路由。

### 7.4 IP 分片题

1. 明确原数据报总长度和首部长度。
2. 算原数据部分长度。
3. 用 `MTU - 首部长度` 得每片最大数据长度。
4. 除最后一片外，每片数据长度取 8B 整数倍。
5. 逐片写总长度、数据长度、MF、片偏移。

### 7.5 TCP 序号确认号题

1. 判断 SYN/FIN 是否占序号。
2. 数据长度为 L，则下一个序号加 L。
3. ACK = 期望收到的下一个字节序号。
4. 累计确认，不是逐字节列举。

### 7.6 TCP 拥塞窗口题

1. 找初始 cwnd 和 ssthresh。
2. cwnd < ssthresh：慢开始，按 RTT 指数增长。
3. cwnd >= ssthresh：拥塞避免，线性增长。
4. 超时：门限减半，cwnd 置小。
5. 三个重复 ACK：快重传/快恢复，按题目给定规则处理。

### 7.7 滑动窗口利用率题

1. 算数据帧发送时延 `Td`。
2. 算确认返回周期 `Td + 2Tp + Tack`。
3. 用窗口 `W` 乘以 `Td` 看能否覆盖等待时间。
4. 需要位数时，再套 GBN/SR 窗口上界。

### 7.8 交换机转发表题

1. 交换机先从源 MAC 学习端口。
2. 查目的 MAC：已知则定向转发，未知则除入端口外泛洪。
3. 广播帧泛洪。
4. 交换机默认不看 IP 作二层转发。
