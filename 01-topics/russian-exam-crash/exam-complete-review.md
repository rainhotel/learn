# 俄语1 期末完整复习文档

## 使用说明

本资料根据三张课堂考点笔记和《俄语1（第二版）》整理。课本来源主要是：

- 书前字母表。
- 语音导论课 Урок 1-12：元音、辅音、重音、弱化、清浊同化、软硬辅音、音节、移行、调型、特殊音组读法。
- 基础课 Урок 1-9：生词表、对话、课文和常用句型。

复习时不要平均用力。按这个顺序背：

1. 字母。
2. 音节和移行。
3. 元音弱化。
4. 清浊辅音同化。
5. 软硬辅音。
6. 调型和调心。
7. 特殊音组读法。
8. 生词选择。
9. 对话和问答。
10. 俄译中、汉译俄。

中文读法都是近似读法，只为考试速成服务。

## 1. 字母

### 知识点

俄语共有 33 个字母：

- 元音 10 个：а, о, у, ы, э, я, ё, ю, е, и。
- 辅音 21 个：б, в, г, д, ж, з, й, к, л, м, н, п, р, с, т, ф, х, ц, ч, ш, щ。
- 符号 2 个：ъ, ь。它们本身不发音。

### 中文近似读法

| 字母 | 读法 | 考试记法 |
|---|---|---|
| а | 啊 | `мама` 里的 `а` |
| о | 哦 | 重读像“哦”，非重读常像“啊” |
| у | 乌 | `му` 近似“木/姆乌” |
| э | 诶 | `это` 开头 |
| и | 衣 | 像“一/衣” |
| ы | 舌头后缩的“呃一” | 汉语没有，先模仿 |
| я | 呀 | `я` 近似“呀” |
| ё | 哟 | 通常带重音 |
| ю | 优 | `ю` 近似“优” |
| е | 耶 | 词首或元音后像“耶” |

### 常考点

- `ь` 是软音符号，不单独发音。
- `ъ` 是硬音符号，不单独发音。
- 字母考试可能要求分类：元音、辅音、符号。
- 也可能要求按字母表顺序写出若干字母。

### 可能试题

1. 写出俄语的 10 个元音。
2. 判断 `ъ` 和 `ь` 是否发音。
3. 将下列字母分类：а, б, о, м, ь, я, ш, ъ。

### 答案

1. `а, о, у, ы, э, я, ё, ю, е, и`。
2. 不发音，只起符号作用。
3. 元音：а, о, я。辅音：б, м, ш。符号：ь, ъ。

## 2. 音节划分

### 知识点

课本规则：一个音节必须有一个元音。一个词有几个元音，通常就有几个音节。

### 做题步骤

1. 先圈元音。
2. 数元音个数。
3. 每个音节保留一个元音。
4. 单个辅音夹在两个元音之间时，通常跟后面的元音。

### 中文近似读法和例子

| 词 | 近似读法 | 音节 |
|---|---|---|
| мама | 妈-ma | ма-ма |
| папа | 帕-pa | па-па |
| кто | kto/克托 | 单音节 |
| что | што/什托 | 单音节 |
| книга | 克尼-ga | кни-га |
| гостиница | 嘎斯-季-尼-ca | гос-ти-ни-ца |
| почему | pa-che-mu/帕-切-木 | по-че-му |

### 可能试题

划分音节：

1. мама
2. книга
3. гостиница
4. сколько
5. почему

### 答案

1. ма-ма
2. кни-га
3. гос-ти-ни-ца
4. сколь-ко
5. по-че-му

## 3. 移行

### 知识点

课本规则：移行按音节进行，但比音节划分更严格。

### 必背规则

- 单音节词不能移行。
- 一个字母不能单独留在行尾，也不能单独移到下一行。
- `ь, ъ, й` 跟前面的字母走，不能单独拆开。
- 双辅音可以拆开。
- 有明显前缀时，可以按前缀移行。

### 例子

| 词 | 可移行 | 不推荐/错误 |
|---|---|---|
| майка | май-ка | ма-йка |
| касса | кас-са | к-асса |
| семья | се-мья | семь-я |
| кто | 不能移 | к-то |
| что | 不能移 | ч-то |

### 可能试题

判断移行是否正确：

1. май-ка
2. ма-йка
3. кас-са
4. к-то
5. се-мья

### 答案

1. 正确。
2. 错，`й` 应跟前面。
3. 正确。
4. 错，`кто` 是单音节词，不能移行。
5. 正确，`ь` 不单独拆开。

## 4. 元音弱化

### 知识点

课本语音导论课讲：重读元音读得清楚、较长；非重读元音读得弱、短。考试常考 `а, о, е, я` 的弱化。

### 考试口诀

- 重音清楚，非重音弱。
- 非重读 `о` 常接近 `а`。
- 非重读 `е, я` 常接近 `и`。
- `ё` 通常自带重音。

### 中文近似读法

| 词 | 近似读法 | 说明 |
|---|---|---|
| молоко | ма-拉-КО | 前两个 `о` 弱化像“啊”，最后重读 |
| хорошо | ха-ра-ШО | 前两个 `о` 弱化，最后重读 |
| Москва | мас-КВА | 非重读 `о` 接近 `а` |
| меня | ми-НЯ | 非重读 `е` 接近 `и` |

### 可能试题

1. `молоко` 中哪些 `о` 弱化？
2. `хорошо` 近似怎么读？
3. `ё` 通常是否带重音？

### 答案

1. 非重读的 `о` 弱化，重读的 `о` 读清楚。
2. 近似 `ха-ра-ШО`。
3. 通常带重音。

## 5. 清浊辅音同化

### 知识点

课本先讲清浊辅音对应，再讲同化。老师笔记也重点写了：

- 浊辅音在词末要清化。
- 浊辅音在清辅音前要清化。
- 清辅音在浊辅音前要浊化。

### 清浊配对

| 浊辅音 | б | в | г | д | ж | з |
|---|---|---|---|---|---|---|
| 清辅音 | п | ф | к | т | ш | с |

### 中文近似读法

| 字母 | 近似 |
|---|---|
| б | b/波 |
| п | p/坡 |
| в | v |
| ф | f |
| г | g/哥 |
| к | k/科 |
| д | d/德 |
| т | t/特 |
| ж | 卷一点的“日” |
| ш | 舌头后一点的“什” |
| з | z |
| с | s |

### 例子

| 词 | 变化 | 近似读法 |
|---|---|---|
| дуб | б 词尾清化成 п | dup |
| город | д 词尾清化成 т | го-рат |
| ложка | ж 在 к 前清化成 ш | лош-ка |
| просьба | с 在 б 前浊化成 з | прозь-ба |

### 注意

`м, н, л, р, й` 是响音，一般不参与普通清浊同化。

### 可能试题

判断下列词是否发生清化或浊化：

1. город
2. дуб
3. ложка
4. просьба

### 答案

1. `д` 在词尾清化，近似 `т`。
2. `б` 在词尾清化，近似 `п`。
3. `ж` 在清辅音 `к` 前清化，近似 `ш`。
4. `с` 在浊辅音 `б` 前浊化，近似 `з`。

## 6. 软硬辅音

### 知识点

课本语音导论课反复讲硬辅音和软辅音。老师笔记也写到“软音跟前面走”，说明移行和读音都会考。

### 判断方法

- `е, ё, и, ю, я` 常使前面的辅音软化。
- `ь` 使前面的辅音软化，本身不发音。
- `ж, ш, ц` 恒硬。
- `ч, щ, й` 恒软。

### 中文近似

硬音像正常发辅音；软音像辅音后面带一点“衣”的感觉。

| 对比 | 近似感觉 |
|---|---|
| ма | 马 |
| мя | 米呀/带软化的 мя |
| на | 纳 |
| ня | 尼呀/带软化的 ня |

### 可能试题

1. `мя` 中 `м` 是硬辅音还是软辅音？
2. `ь` 是否发音？
3. 哪些字母恒硬：ж, ч, ш, щ, ц？

### 答案

1. 软辅音。
2. 不发音，只提示前面辅音软化。
3. 恒硬：ж, ш, ц。恒软：ч, щ。

## 7. 调型和调心

### 知识点

课本语音导论课讲调型。老师笔记写：调型 1, 2, 3，标在元音上，调心在元音上。

考试要做两件事：

1. 判断调型。
2. 标出调心，也就是句子最强调的词的重读元音。

### 调型 1

用途：陈述句。

语气：调心下降，句子说完。

例：

```text
Это мама.
```

近似读法：`诶-ta 妈-ma`。  
意思：这是妈妈。

### 调型 2

用途：特殊疑问句，常有疑问词。

常见疑问词：

| 俄语 | 近似读法 | 中文 |
|---|---|---|
| кто | kto/克托 | 谁 |
| что | што/什托 | 什么 |
| где | gdye/格杰 | 哪里 |
| куда | ку-да/库达 | 去哪里 |
| откуда | от-ку-да/奥特库达 | 从哪里来 |
| как | kak/卡克 | 怎样 |
| какой | ка-кой/卡科伊 | 什么样的 |
| сколько | сколь-ко/斯阔利科 | 多少 |
| почему | по-че-му/帕切木 | 为什么 |
| чей | чей/切伊 | 谁的 |

例：

```text
Кто это?
```

近似读法：`克托 诶-ta`。  
意思：这是谁？

### 调型 3

用途：一般疑问句，也就是“是不是/有没有/对不对”。

语气：调心上升。

例：

```text
Это мама?
```

近似读法：`诶-ta 妈-ma?`  
意思：这是妈妈吗？

老师笔记提示“反问、从句的 3 调型”，做题时只要句子功能像“是不是”的确认问句，优先考虑调型 3。

### 调心位置改变

同一句话，调心不同，意思焦点不同。

```text
Это мама?
```

- 调心在 `мама`：问“这是妈妈吗？”
- 调心在 `это`：问“这个是妈妈吗？”

### 可能试题

判断调型：

1. Это книга.
2. Кто это?
3. Это книга?
4. Где мама?
5. Вы студент?

### 答案

1. 调型 1，陈述句。
2. 调型 2，有疑问词 `кто`。
3. 调型 3，一般疑问。
4. 调型 2，有疑问词 `где`。
5. 调型 3，一般疑问。

## 8. 特殊音组读法

### 知识点

课本语音导论课有“某些辅音音组的读法”。老师笔记写“音组”单独成题。

### 必背表

| 写法 | 近似读法 | 例子 |
|---|---|---|
| что | што/什托 | что |
| его | ево/耶-vo | его |
| конечно | канешна/卡涅什-na | конечно |
| тся, ться | ца/ца | учиться |
| дс, тс | ц | городской |
| сч, зч | щ | счастье |
| сш, зш | шш | сшить |
| стн, здн | 中间音可能脱落 | лестница |

### 可能试题

写出近似读法：

1. что
2. его
3. конечно
4. учиться
5. лестница

### 答案

1. `что` 读近似 `што`。
2. `его` 读近似 `ево`。
3. `конечно` 读近似 `канешна`。
4. `учиться` 中 `ться` 读近似 `ца`。
5. `лестница` 中 `т` 可不明显，近似 `лесница`。

## 10. 对话和问答

### 知识点

老师笔记写“对话”“问答题”。这类题来自基础课对话和课文，核心不是复杂语法，而是固定问答。

### 必背问答

#### 问名字

```text
- Как вас зовут?
- Меня зовут ...
```

近似读法：

- `Как вас зовут?` 卡克 vas za-vut? 你叫什么名字？
- `Меня зовут ...` 米-ня za-vut ... 我叫 ...

#### 问这是谁/这是什么

```text
- Кто это?
- Это мама.
```

```text
- Что это?
- Это книга.
```

#### 问在哪里

```text
- Где книга?
- Книга здесь.
```

意思：

- 书在哪里？
- 书在这里。

#### 问从哪里来

```text
- Откуда вы?
- Я из Китая.
```

意思：

- 您/你们从哪里来？
- 我来自中国。

#### 问是否学生

```text
- Вы студент?
- Да, я студент.
- Нет, я не студент.
```

意思：

- 您是学生吗？
- 是的，我是学生。
- 不，我不是学生。

#### 问会不会说俄语

```text
- Вы говорите по-русски?
- Да, я говорю по-русски.
- Я немного говорю по-русски.
```

意思：

- 您会说俄语吗？
- 是的，我会说俄语。
- 我会说一点俄语。

### 可能试题

根据问句写答句：

1. Как вас зовут?
2. Кто это?
3. Что это?
4. Откуда вы?
5. Вы студент?

### 参考答案

1. Меня зовут ...。
2. Это мама. / Это студент. / Это мой друг.
3. Это книга. / Это аудитория.
4. Я из Китая.
5. Да, я студент. / Нет, я не студент.
