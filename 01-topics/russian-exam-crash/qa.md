# 俄语考试速成 Q&A

## Open Questions

- [ ] 老师是否给过具体调型符号格式？
- [ ] 考试是否要求写俄语手写体，还是只认读？

## Error Patterns

### 把俄语 о 都读成“哦”

- 错因：忽略重音。
- 修正：先找重音，非重读 о 常向 а 靠近。

### 忘记词尾浊辅音清化

- 错因：只背字母本音，不看位置。
- 修正：词尾 б, в, г, д, ж, з 要优先想清化。

### 音节划分不数元音

- 错因：按汉语直觉切词。
- 修正：先圈元音，有几个元音通常几个音节。

### 移行时把 ь/й 分开

- 错因：把 ь/й 当独立音节。
- 修正：ь, ъ, й 跟前一个字母走。

### 调型只看问号

- 错因：一般疑问和特殊疑问混在一起。
- 修正：有疑问词 кто/что/где/когда/как 的，多数先考虑调型 2；没有疑问词的是不是型问句，多数先考虑调型 3。

### 翻译时先想复杂语法

- 错因：试图从零造句。
- 修正：直接套句型：Это ... / У меня есть ... / Я люблю ... / ... находится в ...
