# 俄语考试速成 Solved Problems

## 题型 1：调型

### Problem

判断句子调型：

1. Это мама.
2. Кто это?
3. Это мама?
4. А вы?

### Solution

1. `Это мама.` 是陈述句，用调型 1。
2. `Кто это?` 有疑问词 кто，用调型 2。
3. `Это мама?` 是一般疑问句，用调型 3。
4. `А вы?` 带对比追问，用调型 4。

## 题型 2：音节划分

### Problem

划分音节：мама, папа, университет, гостиница。

### Solution

- мама -> ма-ма。两个 а，所以两个音节。
- папа -> па-па。两个 а，所以两个音节。
- университет -> у-ни-вер-си-тет。五个元音，所以五个音节。
- гостиница -> гос-ти-ни-ца。四个元音，所以四个音节。

## 题型 3：清浊辅音同化

### Problem

判断下列词是否发生清化或同化：дуб, город, ложка, просьба。

### Solution

- дуб：词尾 б 是浊辅音，词尾清化，读近似 дуп。
- город：词尾 д 清化，读近似 горот。
- ложка：ж 在清辅音 к 前清化，读近似 лошка。
- просьба：с 在浊辅音 б 前浊化，读近似 прозьба。

## 题型 4：元音弱化

### Problem

说明 молоко 和 хорошо 中 о 的读法。

### Solution

- молоко：只有重音位置的 о 最清楚，非重读 о 弱化，常向 а 靠近。
- хорошо：非重读 о 弱化，重读 о 清楚。

做题口诀：先找重音，再判断弱化。

## 题型 5：移行

### Problem

判断移行是否合理：

1. май-ка
2. ма-йка
3. кас-са
4. се-мья

### Solution

1. `май-ка` 合理，й 跟前面走。
2. `ма-йка` 不合理，把 й 和前面分开了。
3. `кас-са` 合理，双辅音可拆。
4. `се-мья` 合理，ь 不单独分出，要跟前面辅音结合。

## 题型 6：特殊音组读法

### Problem

写出下列词的常见读法提示：что, его, учиться, конечно, лестница。

### Solution

- что -> што。
- его -> ево。
- учиться -> учица。
- конечно -> канешна。
- лестница -> лесница。

## 题型 7：单词和释义连线

### Problem

连线：

| 俄语 | 释义 |
|---|---|
| университет | 朋友 |
| друг | 大学 |
| книга | 教室 |
| аудитория | 书 |
| преподаватель | 教师 |

### Solution

- университет -> 大学。
- друг -> 朋友。
- книга -> 书。
- аудитория -> 教室。
- преподаватель -> 教师。

## 题型 8：字母书写

### Problem

写出下列字母的大写和小写：а, б, в, м, н, т, р, я。

### Solution

- 印刷体：А а, Б б, В в, М м, Н н, Т т, Р р, Я я。
- 手写体需要按教材字母表临摹，重点注意 т, р, д, г 和英文/汉语直觉不同。

## 题型 9：调心位置改变

### Problem

同一句 `Это мама?` 调心分别放在 `это` 和 `мама`，意思有什么不同？

### Solution

- 调心在 `мама`：问“这是妈妈吗？”重点确认身份是不是妈妈。
- 调心在 `это`：问“这个是妈妈吗？”重点确认所指对象。

考试写法：先圈调心词，再判断句子功能。

## 题型 10：翻译

### Problem

把下列中文译成俄语：

1. 这是我的大学。
2. 我是学生。
3. 我有一本书。
4. 我没有笔。
5. 他会说俄语。
6. 我们大学位于市中心。

### Solution

1. Это мой университет.
2. Я студент.
3. У меня есть книга.
4. У меня нет ручки.
5. Он говорит по-русски.
6. Наш университет находится в центре города.

## 混合自测

### Problem

1. 写出清浊配对：б, в, г, д, ж, з。
2. мама 划音节。
3. город 的词尾 д 怎么读？
4. Кто это? 是什么调型？
5. 翻译：我住在宿舍。

### Solution

1. б-п, в-ф, г-к, д-т, ж-ш, з-с。
2. ма-ма。
3. д 在词尾清化，读近似 т。
4. 有疑问词 кто，用调型 2。
5. Я живу в общежитии.
