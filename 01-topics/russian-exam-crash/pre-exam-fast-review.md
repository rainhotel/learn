# 俄语考前速看

## 怎么用

- 这份只保留临考前最容易考、最容易混、最适合最后扫一遍的点。
- 不追求完整理论，先保证卷面会判断、会标、会解释。
- 看一遍顺序：`调型 -> 调心 -> 音节和移行 -> 清浊同化 -> 音组 -> 元音弱化`。

## 1. 调型和调心

### 先背 4 句

- `ИК-1`：陈述句，`说完了，往下落`
- `ИК-2`：特殊疑问句、命令句，`问具体内容 / 下命令`
- `ИК-3`：一般疑问句，`是不是……？`
- `ИК-4`：对比、追问、话没说完

### 考试速判

- 没问号的普通陈述句：先想 `ИК-1`
- 有问号但没有疑问词：先想 `ИК-3`
- 有 `кто / что / где / как` 这类疑问词：先想 `ИК-2`
- 命令句：先想 `ИК-2`

### 调心是什么

- 调心就是句子里最重要的词。
- 速成判断：`这句话真正想说、想问、想强调的是哪个词`

### 调心一般落在哪个词

- 陈述句：最后一个核心词
- 一般疑问句：最后一个核心词
- 特殊疑问句：疑问词
- 命令句：动词

### 调性标在哪个字母上

- 不标在整个单词上。
- 不标在第一个元音上。
- `标在中心词的重读元音上。`

例子：

- `Это мАма.`：中心词 `мама`，标第一个 `а`
- `Это дОм?`：中心词 `дом`，标 `о`
- `КтО это?`：中心词 `кто`，标 `о`
- `СкажИте!`：中心词 `скажите`，标 `и`

### 如果中心词里有多个元音

- 先找这个词的重音。
- 调性标在这个词的`重读元音`上。

例子：

- `книга` -> `кнИга`
- `студент` -> `студЕнт`
- `окно` -> `окнО`
- `хорошо` -> `хорошО`

### 常见疑问词

| 俄语 | 汉语 |
|---|---|
| кто | 谁 |
| что | 什么 |
| где | 哪里 |
| как | 怎么，如何 |
| когда | 什么时候 |
| почему | 为什么 |
| зачем | 为什么，为了什么 |
| куда | 去哪里 |
| откуда | 从哪里来 |
| сколько | 多少 |
| какой | 哪一种，什么样的 |
| чей | 谁的 |

### 最值钱的 3 个模板

- `Это дОм.` -> `ИК-1` -> 这是房子。
- `Это дОм?` -> `ИК-3` -> 这是房子吗？
- `ГдЕ дом?` -> `ИК-2` -> 房子在哪里？

## 2. 音节划分和移行

### 先记最重要区别

- `音节划分`：按读音结构分
- `移行`：按书写换行规则分
- 两者经常相似，但`不完全一样`

### 音节划分怎么做

- 一个元音就是一个音节核心
- 几个元音，通常就有几个音节
- 一个辅音夹在两个元音中间，通常跟后一个音节
- 多个辅音相连时，通常在中间拆

例子：

- `ма-ма`
- `кни-га`
- `ра-бо-та`
- `пар-та`
- `лам-па`

### `й ь ъ` 的地位

- `й`、`ь`、`ъ` 不单独构成音节
- 它们要依附周围字母来看

例子：

- `май-ка`
- `пись-мо`
- `объ-ём`

### 移行怎么考

- 一般按音节移行
- 一个字母不能单独留在上一行
- 一个字母也不能单独移到下一行
- `й ь ъ` 不和前面的字母硬拆开

典型对比：

- `окно`
  - 音节：`о-кно`
  - 移行：`ок-но`
- `учитель`
  - 音节：`у-чи-тель`
  - 移行：`учи-тель`

### 移行速记

- `按音节移`
- `单个字母不单飞`
- `й ь ъ 不乱拆`

## 3. 清浊辅音同化

### 六对一定背熟

- `б - п`
- `в - ф`
- `г - к`
- `д - т`
- `ж - ш`
- `з - с`

### 这六对怎么发

- `б - п`：双唇音，区别是 `б` 浊、`п` 清
- `в - ф`：唇齿音，区别是 `в` 浊、`ф` 清
- `г - к`：舌后音，区别是 `г` 浊、`к` 清
- `д - т`：舌尖音，区别是 `д` 浊、`т` 清
- `ж - ш`：后部摩擦音，区别是 `ж` 浊、`ш` 清
- `з - с`：舌尖摩擦音，区别是 `з` 浊、`с` 清

最简单判断法：

- 手摸喉咙
- 有振动：浊音
- 没明显振动：清音

### 同化 3 条主规则

1. 词尾浊辅音常清化
   例：`дуб` 读近似 `дуп`

2. 浊辅音在清辅音前常清化
   例：`лодка` 读近似 `лотка`

3. 清辅音在浊辅音前常浊化
   例：`просьба` 读近似 `прозьба`

### 做题就看谁

- 先看词尾
- 再看后一个辅音
- 核心口诀：`前面的音常向后面的音靠`

### 例外先这样记

- `м н л р й` 是响音
- 初级考试里一般不按普通清浊同化处理

## 4. 音组

### 音组是什么

- 音组就是一句话里按`意义和语调`分出来的小块。
- 可以理解成：`一口气里围绕一个小意思单位读出来的一段。`

### 音组怎么划

- 按意义分
- 主句和从句之间常分
- 称呼语前后常分
- 插入语前后常分
- 不要一个词切成一个音组

例子：

- `Это / моя книга.`
- `Когда он пришёл, / мы уже были дома.`
- `Анна, / иди сюда!`
- `К сожалению, / он занят.`

### 音组常考什么

- 给句子划音组
- 说明为什么这样分
- 找每个音组的中心词
- 配合调型一起考

### 回答模板

- `按意义单位划分音组。`
- `主句和从句之间形成音组边界。`
- `称呼语单独构成音组。`
- `插入语单独构成音组。`

## 5. 元音弱化

### 一句话定义

- 元音弱化就是：`非重读元音读得更弱、更短、更模糊。`

### 最常怎么考

- 先让你标重音，再判断哪个元音弱化
- 问 `о` 非重读为什么不像清楚的 `о`
- 给词让你写或判断读音
- 朗读时听你是不是把非重读元音读弱了

### 考试最该记的点

- 先找重音
- 重读元音清楚
- 非重读元音弱化
- `о` 非重读时最典型，常听起来接近 `а`

例子：

- `водА`：前面的 `о` 弱化
- `окнО`：前面的 `о` 弱化
- `молокО`：前两个 `о` 弱化
- `хорошО`：前面的非重读元音弱化

### 考试答题句

- `该词的非重读元音发生弱化。`
- `字母 о 在非重读位置常读得接近 а。`
- `判断弱化前，先确定重音位置。`

## 6. 特别容易一起混的点

### 调心和重音不是一回事

- `重音`：单词内部哪个音节最强
- `调心`：句子里哪个词最重要
- 先找调心词，再在那个词里找重读元音

### 音节划分和移行不是一回事

- 音节按读音
- 移行按书写规则
- `окно` 是最典型例子

### 字母和发音不是一回事

- 拼写里是 `о`
- 非重读时可能听起来接近 `а`
- 所以要把`拼写`和`实际读音变化`分开想

## 7. 进考场前最后背一遍

- `ИК-1` 陈述，`ИК-2` 特殊疑问/命令，`ИК-3` 一般疑问
- 调性标在`中心词的重读元音上`
- 有疑问词多想 `ИК-2`
- 没疑问词但有问号多想 `ИК-3`
- 几个元音通常几个音节
- 音节划分不等于移行
- 词尾浊辅音常清化
- 前音常向后音靠拢
- 音组按意义和语调分
- 非重读元音会弱化，先找重音
