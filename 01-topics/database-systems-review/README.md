## OCR 说明

课件 PDF 是图片型 PPT，没有可直接复制的文字层。已下载 Tesseract 简体中文模型，并使用本地 Tesseract 对 820 页进行 OCR。

OCR 能识别出章节标题、SQL 语句和大部分正文，但少数地方会有错字，例如：

- “冗余”可能识别成“宛余”或“元余”。
- “查询”可能识别成“碍询”。
- “可串行化”可能识别成“可让行化”。

复习资料已经按数据库课程知识对这些 OCR 错误做了人工校正。

## 建议使用顺序

1. 先读 `human-guide.md`，建立复习路线。
2. 系统复习读 `notes.md`。
3. 背诵冲刺读 `formula-sheet.md` 和 `qa.md`。
4. 做题前读 `solved-problems.md`。
5. 需要查课件原文时读 `raw-ppt-ocr.md`。
