# 数据库系统复习导学

## 这门课最容易考什么

从课件范围看，考试大概率围绕 6 条主线：

1. 数据库基本概念和体系结构。
2. 关系数据模型，尤其是关系、元组、属性、域、码、完整性和关系代数。
3. SQL 语句，尤其是查询、连接、嵌套、视图、更新。
4. 数据库设计，尤其是需求分析、E-R 图、E-R 到关系模式转换。
5. 关系规范化，尤其是函数依赖、码、1NF/2NF/3NF/BCNF、模式分解。
6. 并发控制和恢复，尤其是事务 ACID、丢失修改、脏读、不可重复读、锁协议、两段锁、日志和恢复策略。

最重要的不是死背全部课件，而是会做这几类题：

- 写 SQL。
- 写关系代数表达式。
- 判断范式。
- 求候选码。
- 做模式分解。
- 画或转换 E-R 图。
- 判断并发调度问题。
- 判断锁协议能解决什么不一致。
- 解释日志、备份、事务恢复。

## 优先级

### 必拿分

- 数据库、DBMS、DBS 的区别。
- 三级模式两级映像。
- 关系模型三要素。
- 关系、元组、属性、域、分量、关系模式。
- 候选码、主码、主属性、非主属性、外码。
- 实体完整性、参照完整性、用户定义完整性。
- 关系代数：并、差、交、笛卡尔积、选择、投影、连接、除。
- SQL 的组成：DDL、DML、DCL。
- `SELECT-FROM-WHERE-GROUP BY-HAVING-ORDER BY`。
- 连接查询、外连接、嵌套查询、集合查询。
- `INSERT`、`UPDATE`、`DELETE`。
- 视图的定义、作用、更新限制。
- E-R 图基本元素和转换规则。
- 函数依赖、完全/部分/传递依赖。
- 1NF、2NF、3NF、BCNF。
- 事务 ACID。
- 丢失修改、脏读、不可重复读。
- X 锁、S 锁、一级/二级/三级封锁协议、两段锁。
- 备份、日志、系统故障、事务故障、介质故障恢复。

### 中等难度

- SQL 中 `LIKE`、`ESCAPE`、`IS NULL` 的细节。
- `ANY`、`ALL`、`EXISTS` 的嵌套查询。
- 分组查询中 `WHERE` 与 `HAVING` 的区别。
- 视图的 `WITH CHECK OPTION`。
- Armstrong 公理、属性闭包、最小依赖集。
- 无损连接分解和保持函数依赖。

### 容易拉开差距

- 给出函数依赖集，求候选码。
- 判断一个关系模式最高达到第几范式。
- 分解到 3NF 或 BCNF，并说明是否无损、是否保持依赖。
- 根据业务描述画 E-R 图，再转换为关系模式。
- 判断一个调度是否可串行化或是否满足两段锁。

## 复习路线

### 第 1 轮：搭框架

按章节快速过：

```text
数据库概览 -> 关系数据模型 -> SQL -> 数据库设计 -> 规范化 -> 并发与恢复
```

每章只问 3 个问题：

- 这一章解决什么问题？
- 考试会怎么问？
- 我需要会写什么步骤？

### 第 2 轮：做题型

把复习重心转为：

- SQL 写法。
- 关系代数表达式。
- 规范化计算。
- E-R 设计。
- 并发控制判断。
- 恢复策略问答。

### 第 3 轮：背模板

考前只背：

- 定义题模板。
- 简答题模板。
- SQL 模板。
- 范式判断步骤。
- 并发控制对照表。

## 考前一天怎么复习

上午：

- 背 `formula-sheet.md`。
- 写 3 道关系代数和 5 道 SQL。

下午：

- 做 2 道求候选码。
- 做 2 道范式判断和分解。
- 做 1 道 E-R 转关系模式。

晚上：

- 刷 `qa.md`。
- 看 `solved-problems.md` 的标准答题结构。

最后 30 分钟：

- 只看 ACID、三类并发不一致、三级封锁协议、2NF/3NF/BCNF 区别、SQL 语句执行顺序。
