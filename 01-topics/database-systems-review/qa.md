# 高频问答与易错点

## 高频问答

1. 数据库是什么？
   - 长期存储在计算机内、有组织、可共享的大量数据集合。

2. DB、DBMS、DBS 的区别？
   - DB 是数据集合，DBMS 是管理数据库的软件，DBS 是包含 DB、DBMS、应用、用户、DBA 和环境的完整系统。

3. 数据库系统阶段相比文件系统阶段的主要优点？
   - 数据结构化、共享性高、冗余低、独立性高、统一管理控制。

4. 三级模式是什么？
   - 外模式、模式、内模式。

5. 两级映像是什么？
   - 外模式/模式映像，模式/内模式映像。

6. 哪个映像保证逻辑独立性？
   - 外模式/模式映像。

7. 哪个映像保证物理独立性？
   - 模式/内模式映像。

8. 数据模型三要素？
   - 数据结构、数据操作、完整性约束。

9. 关系模型三要素？
   - 关系数据结构、关系操作、关系完整性约束。

10. 一个关系是什么？
    - 一个规范化的二维表。

11. 关系中的行叫什么？
    - 元组。

12. 关系中的列叫什么？
    - 属性。

13. 域是什么？
    - 一组具有相同数据类型的值的集合。

14. 关系的分量有什么要求？
    - 必须是不可再分的原子值。

15. 候选码是什么？
    - 最小的能唯一标识元组的属性集。

16. 主码是什么？
    - 从候选码中选定的一个作为主码。

17. 主属性是什么？
    - 包含在任一候选码中的属性。

18. 外码是什么？
    - 本关系的属性或属性组不是本关系主码，但对应另一个关系的主码。

19. 实体完整性规则？
    - 主码属性不能为空。

20. 参照完整性规则？
    - 外码值必须等于被参照关系某个主码值，或在允许时为空。

21. 用户定义完整性是什么？
    - 针对具体应用语义的约束，如成绩 0-100。

22. 关系代数中选择运算从什么角度操作？
    - 从行的角度选元组。

23. 关系代数中投影运算从什么角度操作？
    - 从列的角度选属性，并去除重复元组。

24. 自然连接有什么特点？
    - 按同名属性等值连接，并去掉重复同名属性列。

25. 除运算常用于表达什么查询？
    - “全部”“至少包含所有”。

26. SQL 的特点？
   - 综合统一、高度非过程化、面向集合、语法简洁、可独立或嵌入使用。

27. SQL 包括哪三类语言？
    - DDL、DML、DCL。

28. `SELECT` 的基本结构？
    - `SELECT-FROM-WHERE-GROUP BY-HAVING-ORDER BY`。

29. `WHERE` 和 `HAVING` 的区别？
    - `WHERE` 过滤分组前元组，`HAVING` 过滤分组后的组。

30. `COUNT(*)` 和 `COUNT(列名)` 的区别？
    - `COUNT(*)` 统计元组数，`COUNT(列名)` 统计该列非空值个数。

31. 判断空值用什么？
    - `IS NULL` 或 `IS NOT NULL`，不能用 `= NULL`。

32. `LIKE` 中 `%` 和 `_` 含义？
    - `%` 表示任意长度字符串，`_` 表示任意单个字符。

33. 外连接和普通连接区别？
    - 普通连接只保留满足条件的元组，外连接还保留某侧或两侧不匹配元组。

34. 什么时候用左外连接？
    - 要保留左表所有元组，即使右表没有匹配。

35. `EXISTS` 看什么？
    - 只看子查询是否返回结果，不关心具体返回值。

36. `UNION` 默认是否去重？
    - 默认去重；不去重用 `UNION ALL`。

37. `DELETE` 和 `DROP TABLE` 区别？
    - `DELETE` 删除表中元组，保留表结构；`DROP TABLE` 删除表结构和数据。

38. 视图是什么？
    - 从一个或多个基本表或视图导出的虚表。

39. 视图有什么作用？
    - 简化操作、多角度看数据、提高逻辑独立性、提供安全保护。

40. `WITH CHECK OPTION` 的作用？
    - 通过视图更新数据时必须满足视图定义条件。

41. `GRANT WITH GRANT OPTION` 作用？
    - 被授权用户可以继续把该权限授予其他用户。

42. `REVOKE ... CASCADE` 作用？
    - 级联回收由该用户传递出去的权限。

43. 数据库设计六阶段？
    - 需求分析、概念结构设计、逻辑结构设计、物理结构设计、数据库实施、运行维护。

44. E-R 模型三要素？
    - 实体、属性、联系。

45. 联系类型有哪些？
    - 1:1、1:n、m:n。

46. m:n 联系如何转关系模式？
    - 单独建一个关系，包含两端实体主码和联系属性，两端主码通常共同组成主码。

47. 局部 E-R 图集成冲突有哪些？
    - 属性冲突、命名冲突、结构冲突。

48. 数据冗余会导致什么异常？
    - 插入异常、删除异常、修改异常。

49. 函数依赖 `X -> Y` 含义？
    - X 值相同则 Y 值也相同，X 函数决定 Y。

50. 候选码是什么？
    - 最小的能决定全部属性的属性集。

51. 主属性是什么？
    - 包含在任一候选码中的属性。

52. 1NF 要求？
    - 属性不可再分。

53. 2NF 要求？
    - 1NF，且每个非主属性完全函数依赖于码。

54. 3NF 要求？
    - 2NF，且非主属性不传递依赖于码。

55. BCNF 要求？
    - 每个非平凡函数依赖的决定因素都是超码。

56. 2NF 消除什么？
    - 非主属性对码的部分依赖。

57. 3NF 消除什么？
    - 非主属性对码的传递依赖。

58. 属性闭包有什么用？
    - 判断函数依赖是否成立、判断超码、求候选码。

59. Armstrong 三条基本公理？
    - 自反律、增广律、传递律。

60. 好的模式分解应满足什么？
    - 无损连接和保持函数依赖。

61. 事务是什么？
    - 一系列数据库操作的有限序列，是并发控制和恢复的基本单位。

62. ACID 是什么？
    - 原子性、一致性、隔离性、持久性。

63. 丢失修改是什么？
    - 两个事务修改同一数据，后写回覆盖前写回。

64. 脏读是什么？
    - 读到另一个事务未提交的数据。

65. 不可重复读是什么？
    - 同一事务两次读取同一数据得到不同结果。

66. X 锁是什么？
    - 排他锁/写锁，加锁事务可读可写，其他事务不能再加锁。

67. S 锁是什么？
    - 共享锁/读锁，加锁事务可读，多个事务可同时加 S 锁。

68. S 锁和 S 锁相容吗？
    - 相容。

69. S 锁和 X 锁相容吗？
    - 不相容。

70. 一级封锁协议解决什么？
    - 防止丢失修改。

71. 二级封锁协议解决什么？
    - 防止丢失修改和脏读。

72. 三级封锁协议解决什么？
    - 防止丢失修改、脏读、不可重复读。

73. 两段锁协议是什么？
    - 事务分为加锁阶段和解锁阶段，加锁阶段不能解锁，解锁阶段不能再加锁。

74. 两段锁协议和可串行化关系？
    - 两段锁是可串行化的充分条件，不是必要条件。

75. 故障类型有哪些？
    - 事务故障、系统故障、介质故障。

76. 日志文件作用？
    - 记录事务更新，用于故障恢复。

77. 系统故障恢复怎么做？
    - UNDO 未完成事务，REDO 已提交但可能未写入数据库的事务。

## 易错点

### 1. DBMS 和 DBS 混淆

DBMS 是软件，DBS 是完整系统。

### 2. 外模式和模式混淆

外模式是用户视图，一个数据库可有多个；模式是全局逻辑结构，一个数据库通常只有一个。

### 3. SQL 执行顺序写错

书写顺序是：

```text
SELECT FROM WHERE GROUP BY HAVING ORDER BY
```

逻辑执行顺序是：

```text
FROM WHERE GROUP BY HAVING SELECT ORDER BY
```

### 4. 空值判断写成 `= NULL`

必须写：

```sql
IS NULL
```

### 5. 聚集函数条件写在 WHERE

错误：

```sql
WHERE COUNT(*) > 3
```

正确：

```sql
HAVING COUNT(*) > 3
```

### 6. 外连接方向选错

题目说“所有学生，即使没选课也显示”，学生表应放左边，用左外连接。

### 7. 视图以为一定能更新

含分组、聚集、去重、多表复杂连接的视图通常不能直接更新。

### 8. 2NF 和 3NF 混淆

2NF 管部分依赖，3NF 管传递依赖。

### 9. BCNF 和 3NF 混淆

BCNF 要求每个决定因素都是码，比 3NF 更严格。

### 10. 候选码没有检查最小性

能决定全部属性只是超码，还必须最小才是候选码。

### 11. 无损连接和保持依赖混淆

无损连接保证分解后能还原关系；保持依赖保证约束能在子模式中检查。

### 12. 两段锁说成必要条件

两段锁是可串行化的充分条件，不是必要条件。

### 13. 一级、二级、三级封锁协议效果混淆

记忆：

```text
一级: 不丢失修改
二级: 不丢失修改 + 不读脏数据
三级: 不丢失修改 + 不读脏数据 + 可重复读
```

### 14. 系统故障和介质故障混淆

系统故障内存丢失、外存数据库没坏；介质故障是磁盘等外存数据被破坏。

### 15. 把候选码和主码混为一谈

候选码可以有多个，主码是从候选码中选出的一个。

### 16. 忘记投影会去重

关系代数的投影结果是关系，关系中不能有重复元组，所以投影后重复行要去掉。

### 17. 不会识别除运算

题目中出现“全部课程”“所有项目”“至少包含集合 S 中全部元素”时，优先想到除运算。
