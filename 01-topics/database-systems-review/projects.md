# 练习与刷题安排

## 1. SQL 必练题

用 `Student(Sno,Sname,Ssex,Sage,Sdept)`、`Course(Cno,Cname,Ccredit)`、`SC(Sno,Cno,Grade)` 练习：

1. 查询所有学生姓名和所在系。
2. 查询计算机系学生。
3. 查询年龄在 18 到 22 的学生。
4. 查询姓刘的学生。
5. 查询没有成绩的选课记录。
6. 查询选修 1 号课程的学生姓名。
7. 查询每门课的平均成绩。
8. 查询平均成绩大于 80 的课程号。
9. 查询没有选课的学生。
10. 查询选修了全部课程的学生。
11. 查询同时选修 1 号和 2 号课程的学生。
12. 查询选课人数最多的课程。

## 1.5 关系代数必练题

用 `Student`、`Course`、`SC` 练习：

1. 查询选修 1 号课程的学生学号。
2. 查询选修 1 号课程的学生姓名。
3. 查询没有选修 1 号课程的学生学号。
4. 查询同时选修 1 号和 2 号课程的学生学号。
5. 查询选修了全部课程的学生学号。
6. 查询至少选修了学生 `95001` 所选全部课程的学生学号。

要求：

- 条件筛选用 `σ`。
- 取列用 `π`。
- 多表关联用连接。
- “全部”优先考虑除运算。

## 3. E-R 图练习

设计以下系统的 E-R 图并转换为关系模式：

1. 学生选课系统。
2. 客户订购商品系统。
3. 图书借阅系统。
4. 教师授课系统。

每题要求：

- 列出实体。
- 列出属性。
- 标出码。
- 标出联系类型。
- 转换为关系模式。
- 标出主键和外键。

## 4. 规范化练习

每道题按固定步骤写：

1. 写属性集。
2. 写函数依赖集。
3. 求候选码。
4. 标主属性和非主属性。
5. 判断 1NF、2NF、3NF、BCNF。
6. 如果不满足，给出分解。

建议题目：

```text
R(A,B,C,D), F={A->B, B->C, A->D}
```

```text
R(A,B,C,D,E), F={AB->C, C->D, D->E}
```

```text
R(Sno,Cno,Sname,Cname,Grade), F={Sno->Sname, Cno->Cname, SnoCno->Grade}
```

```text
R(Sno,Sname,Sdept,Mname), F={Sno->Sname, Sno->Sdept, Sdept->Mname}
```

## 5. 并发控制练习

练习判断：

1. 丢失修改。
2. 脏读。
3. 不可重复读。
4. X/S 锁相容性。
5. 一级封锁协议能否解决某调度问题。
6. 二级封锁协议能否解决某调度问题。
7. 三级封锁协议能否解决某调度问题。
8. 某事务是否满足两段锁协议。

## 6. 恢复练习

练习回答：

1. 事务故障如何恢复？
2. 系统故障如何恢复？
3. 介质故障如何恢复？
4. 静态转储和动态转储区别？
5. 海量转储和增量转储区别？
6. 日志文件记录什么？
7. 为什么动态转储必须配合日志？
