# 《Java 后端与 Agent 工程实战》课程设计

## 课程承诺

帮助具备基本编程经验的学习者，建立 Java 后端核心能力，完成一个可靠消息平台和一个 RAG 知识服务，并具备后端/Agent 应用岗位的项目表达与面试能力。

课程不承诺依靠背诵获得 Offer，也不把堆叠中间件当作工程能力。

## 目标学习者

- 计算机相关专业本科生。
- 学过 Java 语法，但缺乏系统后端能力。
- 做过课程项目或简单 CRUD，希望进入中大厂实习。
- 有 AI/Agent 兴趣，希望补齐传统后端基础。

## 先修要求

- 能使用一种编程语言完成基本程序。
- 了解 Git、命令行和数据库基本操作。
- 了解常见数据结构。
- 每周可投入 20-30 小时完成强化版路线。

## 课程主线

### 主线 A：Java 与后端基础

Java -> 集合 -> 并发 -> JVM -> Spring -> MySQL -> Redis -> MQ -> 可靠性与可观测性。

### 主线 B：工程项目

NotifyFlow 从简单接口逐步演进为可恢复、可观测、可压测的通知平台。

### 主线 C：AI 应用工程

大模型底层 -> 模型推理与服务化 -> Embedding/向量数据库 -> RAG -> Tool Calling -> Agent Runtime -> 评测/安全/成本 -> 接入 NotifyFlow 运维知识场景。

### 主线 D：容器与平台工程

Docker 进程隔离与镜像 -> 网络/存储/资源限制 -> Compose -> Kubernetes 对象与控制器 -> 发布、探针、扩缩容与故障排查。

### 主线 E：多机分布式工程

多实例状态 -> 幂等与一致性 -> 分布式锁/限流 -> 任务分片与租约 -> 服务发现与负载均衡 -> 消息/Outbox/Saga -> 可观测性与故障恢复。

### 主线 F：求职输出

算法 -> 面试问题 -> 项目答辩 -> 简历证据 -> 模拟面试。

## 教学单元类型

### Concept

解释概念、机制和边界。

### Lab

用最小代码验证一个结论。

### Project

将知识应用到 NotifyFlow 或 RAG 服务。

### Incident

构造故障并完成定位、修复和复盘。

### Interview

把知识转成面试表达、手写题和系统设计。

### Teach-back

学习者以教师身份完成试讲或书面教程。

## 评价体系

| 维度 | 权重 | 证据 |
|---|---:|---|
| 原理理解 | 20% | 闭卷问答、机制图 |
| 编码能力 | 20% | 独立实现、代码审查 |
| 工程验证 | 25% | 测试、压测、故障实验 |
| 项目设计 | 15% | ADR、架构答辩 |
| 教学输出 | 10% | 试讲、章节文档 |
| 面试迁移 | 10% | 模拟面试、算法 |

总分达到 80 且每项不低于 60 才算完成模块。

## 课程差异化

- 一套项目贯穿知识，而不是互不相干的 Demo。
- 每个技术组件都回答“为什么需要”和“删掉会怎样”。
- 同时覆盖可靠后端与 Agent/RAG 工程。
- 课程内容直接映射真实 JD 和面经。
- 强制保留实验、指标、失败和决策证据。
- 学习者最终要能教会别人，而不是只会背答案。

## V1.0 扩展模块

### 大模型与 AI 应用原理

1. Tokenization、Embedding 与语言模型目标。
2. Transformer、Self-Attention、位置编码与上下文窗口。
3. 预训练、SFT、偏好对齐与工具使用学习。
4. 推理采样、Temperature、Top-p、KV Cache、批处理与量化。
5. 模型 API、流式输出、结构化输出和服务超时。
6. Embedding 服务、向量检索、RAG 与评测。
7. Tool Calling、工作流、Agent Loop、Memory、MCP。
8. Prompt Injection、数据权限、沙箱、成本和可观测性。

### Docker 与 Kubernetes

1. Linux namespace、cgroup、容器进程模型。
2. 镜像层、UnionFS、Dockerfile、缓存与安全。
3. 容器网络、卷、日志、健康检查和资源限制。
4. Compose 多服务本地环境。
5. Kubernetes 控制面、etcd、API Server、Scheduler、Controller、Kubelet。
6. Pod、Deployment、Service、ConfigMap、Secret、Job。
7. requests/limits、探针、滚动更新、回滚和 HPA。
8. 日志、事件、网络排查、RBAC 和最小权限。

### 多机分布式真实场景

1. 多实例任务重复执行。
2. 分布式幂等与唯一约束。
3. 分布式锁与租约失效。
4. 分布式限流与配额分配。
5. 任务分片、消费者组和租约续期。
6. 服务发现、负载均衡和故障转移。
7. Outbox、Saga 和外部副作用补偿。
8. 时钟、网络分区、重试风暴和降级。
9. 多实例日志、TraceId 和指标聚合。
10. 滚动发布、版本兼容和数据迁移。
