# 8 周完整路线

## Week 1：事实核验、Java 基础与项目骨架

### 知识

- Java 类型系统、String、equals/hashCode、集合、异常、泛型。
- HashMap、ConcurrentHashMap、ArrayList 的核心实现与复杂度。
- Maven、JUnit 5、Spring Boot 基础分层。

### 项目

- 完成大烨实习事实台账。
- 建立通知平台仓库：用户、模板、通知任务、渠道四个最小领域对象。
- MySQL 建表、Flyway 迁移、REST API、统一异常和参数校验。

### 算法

- 数组、链表、哈希、双指针，共 12-15 题。

### 验收

- 闭卷实现 LRU 或简化 HashMap 相关结构。
- 能解释每张表的主键、唯一键、索引和状态字段。
- 形成真实实习与暑期重构的明确边界。

## Week 2：并发、线程池与异步任务

### 知识

- JMM、happens-before、volatile、synchronized、CAS、AQS。
- ThreadLocal、线程池七参数、队列与拒绝策略。
- CompletableFuture 异常、超时、组合和线程池隔离。

### 项目

- 通知任务异步执行；邮件、短信使用渠道 SPI。
- 使用有界线程池、超时、取消和并发配额。
- 用 JMH/压测对比串行、无界并发和有界并发。

### 算法

- 栈、队列、二叉树，共 12-15 题。

### 验收

- 能根据任务类型解释线程池参数，而不是背公式。
- 展示队列满、拒绝、超时和优雅停机行为。

## Week 3：MySQL、事务与数据一致性

### 知识

- B+Tree、聚簇/二级索引、覆盖索引、回表、最左前缀。
- MVCC、隔离级别、间隙锁、死锁、事务失效。
- Explain、慢 SQL、分页和批量写入。

### 项目

- 通知任务状态机与幂等键。
- 设计批量任务、发送明细和审计事件。
- 模拟重复请求、并发更新、事务回滚和死锁。

### 算法

- 二分、堆、区间，共 10-12 题。

### 验收

- 用执行计划证明一次索引优化。
- 解释为什么数据库事务无法覆盖短信/邮件外部副作用。

## Week 4：Redis 与缓存工程

### 知识

- String、Hash、List、Set、ZSet、Bitmap、HyperLogLog、Stream。
- RDB/AOF、过期删除、内存淘汰、主从和哨兵概念。
- 穿透、击穿、雪崩、热 Key、大 Key和缓存一致性。
- Redisson 锁的看门狗、续期、可重入和失效边界。

### 项目

- Redis 实现限流、幂等短期状态、模板缓存或任务进度。
- 只在有明确收益的位置使用缓存。
- 构造缓存击穿和热 Key 实验。

### 算法

- DFS、BFS、回溯，共 10-12 题。

### 验收

- 能解释 Redis 用在项目中的必要性、数据结构和一致性策略。
- 不把 Redis 当成“为了简历存在”的组件。

## Week 5：消息队列与可靠消息

### 知识

- 深入学习 Kafka；RocketMQ 作为中国 Java/先进制造岗位的事务、FIFO 和延迟消息对照。
- Producer ACK、Broker 持久化、Consumer Group、Offset。
- 重复消费、消息丢失、顺序、积压、重试、死信和延迟消息。
- 至少一次、至多一次、所谓“恰好一次”的边界。

### 项目

- 引入 MQ 解耦任务提交与渠道执行。
- Transactional Outbox 保证数据库状态和消息发布最终一致。
- 消费端幂等、指数退避、死信处理和人工重放。

### 算法

- 图、拓扑排序、并查集，共 10-12 题。

### 验收

- 停止消费者制造积压，再恢复并观察吞吐。
- 模拟重复投递和消费者崩溃，证明副作用可控。
- 能回答 Kafka 分区内顺序与 Java 客户端顺序保证。

## Week 6：Spring、JVM、网络与生产排障

### 知识

- IOC、Bean 生命周期、循环依赖、AOP、事务传播和失效场景。
- JVM 内存、类加载、对象分配、GC 算法和常见收集器。
- OOM、CPU 飙高、死锁、频繁 GC 的排查方法。
- TCP、HTTP/HTTPS、连接池、DNS、长短连接。

### 项目

- Actuator/Micrometer 指标、结构化日志和 traceId。
- 记录成功率、P95、队列深度、重试数和死信数。
- 进行 CPU、内存、数据库连接池或线程池故障实验。

### 算法

- 动态规划基础，共 10-12 题。

### 验收

- 完成一份生产故障复盘报告。
- 使用线程 dump、堆信息或指标定位一次人为故障。

## Week 7：向量数据库与 RAG 工程

### 知识

- Embedding、距离度量、维度和归一化。
- Chunk 大小、重叠、结构化切分和元数据。
- HNSW、IVF 的基本原理与精度/速度/内存权衡。
- Dense、BM25、Hybrid Search、Metadata Filter、Rerank。
- Recall@K、MRR、nDCG、答案正确性、忠实度和引用。

### 技术选择

- Java 编排优先选择 Spring AI 或 LangChain4j 其中一个。
- 向量库优先选择 pgvector 或 Milvus 其中一个。
- 若希望降低运维复杂度，用 PostgreSQL + pgvector；若希望展示独立向量库工程能力，用 Milvus。

### 项目

- 建立运维/产品知识库：文档导入、切分、Embedding、索引、检索、重排和引用。
- 将 RAG 作为独立模块接入通知平台，例如为故障告警生成带证据的处理建议。
- 创建 30-50 条黄金问题集，对比不同切分与检索策略。

### 算法

- 综合限时题和弱项复习，共 8-10 题。

### 验收

- 展示一次“召回到了但回答错误”和“根本没召回到”的区别。
- 给出至少两组可比较的 RAG 评测数据。
- 回答向量库为什么不能完全替代关键词搜索。

## Week 8：简历、面试与投递演练

### 简历

- 大烨实习只保留真实内容并加强问题、行动和结果。
- 新增“消息通知平台工程化重构”独立项目。
- Agent 版突出 RAG/Runtime；Java 版突出并发、MySQL、Redis、MQ 和可靠性。

### 面试

- 3 次模拟面试：Java 基础、项目深挖、系统设计。
- 2 次 45 分钟算法模拟。
- 录制 90 秒自我介绍、5 分钟项目介绍和 15 分钟架构答辩。

### 投递材料

- README、架构图、ER 图、时序图、压测报告、故障复盘、RAG 评测报告。
- 每个简历技术词关联到代码、实验或文档。

### 最终验收

- 随机抽取 `qa.md` 中 40 个问题，正确率达到 80%，且能结合项目回答。
- 能从零设计一个可靠通知系统和一个基础 RAG 服务。
- 简历中没有无法证明或无法深入解释的技术栈。

## 扩展周期：AI、容器与多机分布式（在 8 周基础路线后继续）

### Module A：大模型底层原理

- Token、Embedding、Logits、Loss。
- Transformer、Attention、位置编码、上下文窗口。
- 预训练、SFT、RL/偏好对齐的工程边界。
- 推理采样、KV Cache、批处理、量化、吞吐与延迟。
- 模型服务接口、流式响应和超时/重试。

### Module B：AI 应用与 Agent 原理

- RAG 数据管道、向量检索、混合召回、重排和评测。
- Tool Calling、结构化输出、工作流与 Agent Loop。
- Memory、Checkpoint、MCP、权限、沙箱和人工审批。
- Prompt Injection、敏感数据、成本和可观测性。

### Module C：Docker 原理与工程

- Namespace、cgroup、容器进程、镜像层和 UnionFS。
- Dockerfile、缓存、网络、卷、日志、健康检查。
- Compose 本地复现 MySQL/Redis/MQ/向量库/应用。
- 资源限制、非 root、镜像瘦身和供应链安全。

### Module D：Kubernetes 入门与真实运维

- 控制面和数据面组件。
- Pod、Deployment、Service、ConfigMap、Secret、Job。
- requests/limits、探针、滚动发布、回滚、HPA。
- 服务访问、DNS、日志、事件、故障排查和 RBAC。

### Module E：多机分布式系统

- 多实例任务重复、幂等、租约和分片。
- 分布式锁、限流、服务发现、负载均衡。
- MQ 消费者组、Outbox、Saga 和补偿。
- 网络分区、时钟、重试风暴、降级和数据迁移。
- 分布式可观测性与事故复盘。

每个扩展模块必须绑定真实项目需求：模型知识助手、容器化 NotifyFlow、Kubernetes 滚动发布、多实例任务领取和故障恢复，不能只停留在概念笔记。
