## 后续变更规则

每次追加证据时必须记录：

- 变更日期、课程版本和对应章节。
- 新增或替换的原始证据文件。
- 环境、命令、退出码、数据集或学习者样本变化。
- 状态提升或回退的理由。
- 已知限制和发布决定是否变化。

不得只更新“通过”字样而不链接证据。
