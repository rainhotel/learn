本目录是内部发布审计快照，用于把已经存在的课程内容、实验事实和未完成门禁放到同一证据链中。它不是 V1.0 成品、Release Candidate、学习者交付压缩包或销售许可证。

## 2. 本次纳入范围

- `course/01-*` 至 `course/23-*` 的课程章节、实验说明和当前源码/配置。
- 课程产品文件，包括产品规格、依赖图、学习路线、术语表、证据矩阵与发布检查表。
- 截至本证据包生成时能够从当前工作区直接观察到的工具版本和自动审计结果。
- 已有实验状态的索引；只有被明确限定的既有运行结果可以写入“已观察”范围。
- 当前学习者验证、模拟面试、许可证、隐私和安全门禁的真实状态。

关键控制文件：

- [课程产品规格](../../product-spec.md)
- [章节证据矩阵](../../evidence-matrix.md)
- [课程发布检查表](../../release-checklist.md)
- [课程质量审计](../../quality-audit-2026-07-15.md)

## 3. 本次不纳入或尚未形成的内容

- 未运行实验的成功结论、性能数字或生产级结论。
- 第 05-23 章中仍为 `Pending` 的真实组件、故障注入、RAG、Agent、容器、集群和多机结果。
- 学生版与教师版的独立构建产物、答案隔离验证和最终销售压缩包。
- 陌生学习者端到端完成记录、正式 Teach-back、三轮模拟面试和真实投递反馈。
- 实时 JD 样本、岗位数量、薪资区间或关键词频率结论。
- 已完成的版权法律审查、依赖许可证清单、SBOM、模型/数据集使用授权。
- 正式隐私影响评估、渗透测试、供应链安全审计或 Git 历史 Secret 扫描。

## 4. 证据口径

本证据包沿用课程的 L1-L7 证据等级。静态检查不等于组件运行，确定性模型不等于生产压测，本机运行不等于陌生环境复现，作者自测不等于学习者独立完成。

任何文件之间出现状态冲突时，采用以下顺序：

1. 本次真实命令输出和原始运行记录。
2. [章节状态表](./chapter-status.csv) 中带范围限定的记录。
3. [章节证据矩阵](../../evidence-matrix.md)。
4. 讲义、实验计划或设计文档。

设计文档只能证明课程已经定义了如何验证，不能证明验证已经发生。

## 5. 使用限制

本快照可用于内部审校、安排实验、组织 Alpha 试教和追踪发布阻塞。当前不得将其用于宣称课程已经全部实验通过、已经被学习者验证、已经完成版权清理或已经达到可正式售卖状态。
