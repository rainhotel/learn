# 面试验证证据

## 1. 当前事实

```text
正式组合模拟面试轮数：0
带录音或完整转写的轮数：0
带评分表和证据追问的轮数：0
完成一周后复测的轮数：0
真实投递面试反馈样本数：0
```

课程已经建立题库、追问树、评分和复测协议，但这些设计不能证明学习者当前能够闭卷作答、纠正错误前提、打开项目证据或完成系统设计。因此第 21 章与整课求职门禁仍未通过。

## 2. 每轮必须归档

- 匿名 candidate ID、日期、面试轮次、面试官角色和课程版本。
- 题目抽样规则、未提前泄露声明和实际时长。
- 录音/转写授权、原始作答、提示次数和追问路径。
- Java、数据库、中间件、JVM、项目、RAG/Agent 与系统设计分项评分。
- 被要求打开的代码、SQL、日志、指标、JFR 或实验报告链接。
- 错误事实、证据不足、表达问题、改进任务和负责人。
- 一周后同构复测结果与跨轮变化。
- 若来自真实招聘流程，只保留脱敏、经授权且不违反保密义务的信息。

## 3. 发布判定边界

至少三轮组合模拟面试是课程发布检查表的必要条件之一，但三轮完成也不自动证明面试成功率，更不能形成 offer、薪资或原题命中承诺。只有可追溯的原始作答、统一评分和复测改善才可作为教学有效性的受限证据。
