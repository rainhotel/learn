# 已知限制

## 1. 发布等级限制

- 当前整课状态为 `Internal Alpha`，不是 Release Candidate。
- 第 01-23 章虽然都具备标准文件结构，但结构完整不等于实验、教学和商业交付完成。
- 没有任何章节达到 `Released`，整套课程不得以 V1.0 正式成品宣传。

## 2. 实验与工程限制

- 第 01-04 章已有运行记录，但本证据包尚未收齐逐次命令、退出码、原始输出、环境快照与源码版本。
- 第 05 章尚无成功归档的 Spring 事务测试结果；Maven 客户端存在不等于依赖解析和测试已经通过。
- Docker daemon 当前不可连接，Redis、Kafka、Compose、Docker、Kubernetes 和多机主线没有本次运行证据。
- k6 当前未安装，第 09 章只有 k6 脚本静态检查，不存在开放负载 threshold 运行结果。
- 第 10-19 章的 JVM、网络、容器、集群、LLM、RAG、Agent 和多实例实验大部分保持 Pending。
- NotifyFlow 尚无经过干净环境验证的一键启动主纵切，章节实验尚未形成完整端到端业务闭环。

## 3. 教学与求职限制

- 没有真实学习者完成一个完整模块，也没有学习时长、卡点和修订的 Alpha 数据。
- 第 01-23 章核心作业、Teach-back 和陌生读者测试没有形成正式验证记录。
- 尚未完成三轮有录音/转写、评分表和一周复测的模拟面试。
- 大烨实习事实台账尚未逐句获得用户确认，不能把独立项目新增技术写回实习经历。
- Playwright 公开岗位访问此前因审批 403 未形成实时 JD 样本；当前没有岗位数量、薪资或关键词频率结论。
- 没有真实投递反馈证明简历、项目表达或课程训练对招聘结果的影响。

## 4. 内容与交付限制

- 当前没有自动生成并验收的学生包和教师包，答案尚未经过发布构建隔离验证。
- 自动链接审计只检查本地 Markdown 路径，不检查外部 URL 可达性、页面锚点或渲染后的导航体验。
- 没有经过非作者的逐章技术审校和教学审校。
- 尚无样章销售页、支持/退款政策、勘误入口和最终交付压缩包验收。

## 5. 合规与安全限制

- 仓库根目录和课程目录均未发现 `LICENSE`、`COPYING` 或 `NOTICE` 文件，当前没有明确的对外分发许可策略。
- 第三方代码、依赖、模型、数据集、题目和长引用尚未形成完整许可证清单或 SBOM。
- 当前只做了课程目录的基础文本 Secret/PII 模式扫描，不是完整隐私、安全或 Git 历史审计。
- 工作区根目录存在课程范围外的 `.env` 文件；任何发布构建都不得直接打包整个仓库。
- 日后加入简历、面试、JD、运行日志和截图时，仍需逐项匿名化并复查企业数据与个人联系方式。

## 6. 解释边界

本证据包中记录的 L4 结果只证明确定性模型内的关系；L5 本机结果只证明限定版本和限定路径曾运行。它们都不能推出生产容量、线上稳定性、通用模型质量、课程完成率或 offer 成功率。
