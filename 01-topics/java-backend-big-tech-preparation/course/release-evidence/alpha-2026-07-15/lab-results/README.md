## 2. 后续每次实验必须保存

每个实验使用独立子目录，并至少包含：

- 实验 ID、章节、日期和执行者。
- Git commit 加工作区差异标识，或不可变源码归档 hash。
- OS、CPU、内存、JDK、依赖、中间件和配置版本。
- 数据集/负载、前置状态、执行命令、退出码和原始 stdout/stderr。
- 断言结果、数据库/消息/副作用最终状态和清理结果。
- 故障注入、检测、止血、恢复、对账的时间线。
- 该实验能证明什么、不能证明什么。

性能实验还必须保存吞吐、错误率、P50/P95/P99、资源指标、预热、持续时间和重复次数。只保存截图或人工总结不能替代原始数据。

## 3. 状态提升规则

只有原始证据已归档、结论可在固定环境复现且章节核心断言全部通过，才可以提议 `Lab Verified`。提议仍需经过课程发布审计；单个实验通过不能自动提升整章或整课状态。
