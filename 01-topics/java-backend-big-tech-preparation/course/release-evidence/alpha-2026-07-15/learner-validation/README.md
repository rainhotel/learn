# 学习者验证证据

## 1. 当前事实

```text
正式学习者样本数：0
独立完成的完整模块数：0
正式 Teach-back 记录数：0
陌生学习者端到端复现数：0
```

当前没有证据证明陌生学习者能够在不依赖作者临场帮助的情况下理解、运行并完成课程模块。因此整课保持 `Internal Alpha`，任何章节均不能据此标记 `Teach Verified`。

## 2. 首轮 Alpha 必须记录

每名参与者使用匿名 ID，并为每个模块保存：

- 入学基线、相关经验和使用的学习路径。
- 开始/结束时间、有效学习时长、环境与是否获得提示。
- 作业首次提交、实验原始输出、评分和失败重试。
- 卡点、错误理解、文档缺口、作者额外口头帮助。
- 5/15/45 分钟 Teach-back 的录音或转写、评分和听众问题。
- 修订前后课程版本，以及修订后独立复测结果。
- 明确授权、数据保留期限和匿名化检查结果。

## 3. 最低提升条件

单章提议 `Teach Verified` 至少需要一名非作者学习者独立完成核心作业和实验，并通过未看答案的 Teach-back；整课进入 Release Candidate 还需要覆盖核心路径的多名/多入口验证、答案隔离和陌生环境复现。单个满意度评分或作者陪跑完成不能替代这些证据。
