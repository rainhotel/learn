# 第 21 章 Teach-back

## 5 分钟：一个机制

随机抽取线程池、JMM、事务、缓存、消息、GC、网络或 RAG 中一个主题，按“问题—机制—场景—失败—证据—边界”回答，不背定义列表。

## 15 分钟：一个项目难点

讲 NotifyFlow 的创建、Outbox、消费、Provider timeout、UNKNOWN 和对账，接受至少五层追问，并指出哪些实验已运行、哪些仍为 Pending。

## 45 分钟：组合模拟面试

```text
Java/JMM 8 分钟
Spring/数据/MQ 8 分钟
JVM/网络/容器 6 分钟
项目深挖 10 分钟
RAG/Agent 5 分钟
系统设计 8 分钟
```

## 验收

- 首句先给结论，再给机制和证据。
- 每个技术词都能回答替代方案和失败模式。
- 不用“底层就是”“高并发”“生产级”等空泛措辞。
- 无法确认时明确未知，并给出验证方法。
- 面试结束后将弱项回写章节、练习和下一次复测日期。
