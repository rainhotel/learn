# 第 18 章面试追问

## Agent 与工作流区别？

工作流由代码决定步骤；Agent 在受限候选中动态选择。权限、预算、执行和状态机仍由代码控制。

## Tool timeout 如何处理？

如果副作用可能已发生，进入 UNKNOWN，停止普通重试，通过查询、回调或对账收敛。

## Memory 如何设计？

会话/工作记忆可截断，长期知识要版本与权限，业务状态必须存数据库/事件；摘要引用原始证据。

## 多 Agent 一定更好吗？

不一定。它增加消息、成本、延迟、冲突和观察难度，只有任务分解/权限隔离带来明确收益才使用，并与基线消融。

## 如何防 prompt injection？

把文档/工具结果视为不可信数据；系统规则和权限不由内容覆盖；schema、allowlist、最小权限、隔离执行、审批和审计。

## Java 如何实现 Agent SSE？

持久化 run event，SSE 只是投递；支持 Last-Event-ID、取消、超时、背压和客户端断线，工具执行状态独立存在。

## 如何评测 Agent？

任务完成、工具选择/参数、引用、安全、幂等、UNKNOWN 收敛、崩溃恢复、延迟、token 和成本分开评测。
