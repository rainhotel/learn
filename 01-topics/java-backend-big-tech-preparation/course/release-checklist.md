# 《Java 后端与 Agent 工程实战》发布检查表

## 1. 用途

本文件是从内部 Alpha 推进到 Release Candidate 和 Released 的统一门禁。它不替代各章 `lab/README.md`，而是检查整套课程能否被陌生学习者购买、理解、运行、完成和复核。

当前判定：`Internal Alpha`。所有未真实完成项保持未勾选，不能因为存在设计文档而视为通过。

## 2. 发布状态

| 状态 | 必须满足 |
|---|---|
| Draft | 内容可读，来源与 Pending 边界明确 |
| Lab Verified | 章节承诺的核心实验在固定环境真实运行并保存原始证据 |
| Teach Verified | 学习者独立完成作业与 Teach-back，问题已回写修订 |
| Release Candidate | 产品、内容、实验、教学、求职、版权与复现门禁全部通过 |
| Released | 陌生学习者完成端到端试用，阻断问题关闭，并发布版本与勘误入口 |

章节状态不能自动提升整课状态。整课取所有阻断门禁中的最低状态。
