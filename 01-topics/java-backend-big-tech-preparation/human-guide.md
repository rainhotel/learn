# Java 后端暑期导学

## 核心策略

这个暑假不以“看完多少课程”为目标，而以四种证据为目标：

- 能写：不依赖 AI 完成核心代码。
- 能讲：解释机制、边界和替代方案。
- 能测：有单元测试、压测和故障实验。
- 能复盘：说明为什么这样设计，以及下一版会怎么改。

## 学习优先级

### P0：必须掌握

- Java 基础、集合、异常、泛型、反射和 IO。
- 并发、JMM、锁、线程池、CompletableFuture。
- JVM 内存、类加载、GC 和问题排查。
- Spring Boot、IOC、AOP、事务、MVC。
- MySQL 索引、事务、锁、MVCC、SQL 优化。
- Redis 数据结构、缓存问题、持久化、分布式锁。
- 消息队列的可靠投递、重复、顺序、积压和消费失败。
- HTTP/TCP 基础、Linux、Git、Docker、日志与监控。
- 数据结构与算法。

### P1：形成项目优势

- 幂等、重试、超时、限流、熔断、背压和补偿。
- 任务状态机、Outbox、延迟任务、死信队列。
- Testcontainers、接口测试、压测和故障注入。
- RAG：切分、Embedding、向量索引、混合检索、重排、引用和评测。

### P2：了解即可

- 微服务全家桶的所有组件。
- Kubernetes 复杂运维。
- 自研分布式事务框架。
- 多种消息队列、多个向量库横向堆叠。
- 大模型预训练、SFT、RL 的深入算法实现。

## 每日最低结构

- 90 分钟：Java/后端原理。
- 120 分钟：项目编码和测试。
- 45 分钟：算法。
- 30 分钟：口述复盘或面经问题。
- 15 分钟：记录证据、错误和下一步。

## AI 辅助开发规则

- 先自己写设计和接口，再让 AI 提建议。
- 核心并发、事务和幂等代码必须自己解释每一行。
- AI 生成的代码必须经过测试、日志和故障实验验证。
- 保存关键提示、修改记录和人工决策，形成“AI 协作工程能力”证据。
- 面试前必须能在无 AI 情况下实现核心数据结构和业务流程。

## 暑假后的合格状态

面对一个消息发送接口，你应能从 API、数据库、缓存、队列、线程池、幂等、失败恢复、监控和压测一路讲到底；面对一个 RAG 问答错误，你应能区分数据、切分、召回、重排、上下文和生成阶段的问题。
