# Algorithm Final Review Notes

## 考试统一写法

### 为什么这里不默认用 `bits/stdc++.h`

- 你给出的图片上写了 `#include <bits/stdc++.h>`，这在很多 `OJ` 上确实常见。
- 但你又明确说要按 `C++98` 标准准备，所以这里默认用标准头文件。
- 这样做的好处是考试环境更稳，也更符合“老师看板子就知道你写的是什么”的风格。

### 建议固定背下来的头文件组合

```cpp
#include <iostream>
#include <cstdio>
#include <cstring>
#include <algorithm>
#include <queue>
#include <vector>
#include <utility>
using namespace std;
```

### 考场里先统一想清楚的 4 件事

1. 下标是从 `0` 开始还是从 `1` 开始。
2. 这题的“状态”或“当前点”到底表示什么。
3. 哪个数组需要初始化，初值是多少。
4. 答案是方案数、最值、步数，还是可行性。

## 1. DFS / BFS

### 这类题常见长相

- 迷宫能不能走到终点。
- 有多少个连通块、岛屿、区域。
- 从起点走到终点的最少步数。
- 图或网格的遍历。

### 怎么判断用 DFS 还是 BFS

- 只需要“搜到所有点”或“统计块数”，优先 `DFS`。
- 需要“最少步数”，优先 `BFS`。
- 边权都相同且每次走一步，`BFS` 的最短路最稳。

### 这类题最容易错的地方

- 忘记 `visited`。
- 明明已经访问过，还重复入队或递归。
- 越界判断顺序写错。
- `BFS` 把第一次到达终点之外的更长路径也算进去。

## 2. 二分查找

### 这类题常见长相

- 在有序数组里找某个值第一次出现的位置。
- 找第一个大于等于 `x` 的位置。
- 找最后一个小于等于 `x` 的位置。
- 问某个答案能不能做到，然后在答案空间二分。

### `lower_bound` 和 `upper_bound`

- `lower_bound`：第一个 `>= x` 的位置。
- `upper_bound`：第一个 `> x` 的位置。
- 如果要统计值 `x` 的出现次数，答案就是 `upper_bound - lower_bound`。

### 最容易错的地方

- 数组没排序就二分。
- `l`、`r` 的含义没统一，一个写闭区间，一个写开区间。
- 找“最后一个满足条件”的时候仍然套“第一个满足条件”的模板。

## 3. 贪心

### 贪心没有单一万能模板

- 它更像一种策略：每一步先做当前看起来最优的选择。
- 真正关键不是会背代码，而是会看“局部最优能不能推出整体最优”。

### 这门课里最值得先背的题型

- 活动选择 / 区间不重叠最大数量。
- 按某个关键字排序后做线性扫描。
- 用一个变量维护当前最优边界或剩余资源。

### 最容易错的地方

- 只觉得“看起来合理”，但不会解释为什么能贪。
- 排序依据选错。
- 相等边界时是 `<` 还是 `<=` 没想清楚。

## 4. 动态规划

### 动规统一四问

1. `dp[i]` 或 `dp[i][j]` 表示什么。
2. 当前状态从哪些更小状态转移而来。
3. 初值是什么。
4. 按什么顺序遍历，才能保证前驱已经算出。

### 4.1 最大子段和

- 经典状态：`dp[i]` 表示“以 `a[i]` 结尾的最大子段和”。
- 转移：要么单独从 `a[i]` 开始，要么接在 `dp[i - 1]` 后面。
- 最后答案是所有 `dp[i]` 的最大值。

### 4.2 最长不降子序列

- 经典状态：`dp[i]` 表示“以 `a[i]` 结尾的最长不降子序列长度”。
- 转移：枚举 `j < i`，如果 `a[j] <= a[i]`，则可接上。
- 这是最适合考场默写的 `O(n^2)` 版本。

### 4.3 `0/1` 背包

- 经典状态：`dp[j]` 表示“容量为 `j` 时的最大价值”。
- 每个物品只能用一次，所以容量必须倒着枚举。
- 如果写成正着循环，就会变成“完全背包”。

### 4.4 最长公共子序列

- 状态：`dp[i][j]` 表示 `a` 的前 `i` 个字符和 `b` 的前 `j` 个字符的 `LCS` 长度。
- 如果当前字符相等，就从左上角转移 `+1`。
- 如果不等，就取上方和左方的较大值。

## 5. 图论

### 5.1 `Floyd`

- 适用场景：要求任意两点最短路，点数不大。
- 核心思想：枚举中转点 `k`，尝试用 `k` 改善 `i -> j` 的最短路。
- 板子很整齐，但复杂度是 `O(n^3)`。

### 5.2 最小生成树

- 如果题目要“把所有点连起来，总边权最小”，优先想到最小生成树。
- 考试优先背 `Kruskal`：
  - 思路直观：边按权值从小到大排，能连就连。
  - 关键在并查集判断是否成环。
- 如果老师更偏矩阵写法，再额外会一个 `Prim` 思路即可。

## 小改题怎么改

### 搜索题

- 障碍条件变了：改合法性判断。
- 起点终点变了：改初始入栈 / 入队位置。
- 统计连通块改成最短路：`DFS` 思路换成 `BFS`。

### 二分题

- “第一个 `>= x`”改“第一个 `> x`”：只改比较符号。
- “查值”改“查答案”：把数组二分换成判定函数二分。

### DP 题

- 最值改计数：`max` 往往改成加法。
- 最长上升改最长不降：`<` 改成 `<=`。
- `0/1` 背包改完全背包：容量循环方向从倒序改成正序。

### 图题

- `Floyd` 改有重边：建图时取更小权值。
- 最小生成树改判断能否连通：最后检查选边数是否等于 `n - 1`。
