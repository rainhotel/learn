# Algorithm Final Review Classic Problems

## 使用方式

- 先做“必做题”，每类至少 1 道。
- 动态规划至少做 2 到 3 道，因为它最容易在状态定义和循环顺序上丢分。
- 如果时间紧，只做标记为“优先”的题。
- 所有代码默认按 `Dev-C++ / C++98` 写，不使用 `auto`、范围 `for`、`bits/stdc++.h` 作为正式板子。

## 1. DFS / BFS

### 必做题

1. `POJ 2386 - Lake Counting`
   - 类型：`DFS` / 连通块计数
   - 练什么：从一个水洼格子开始，把相邻水洼全部搜掉。
   - 重点：这题常用 8 个方向，不是 4 个方向。
   - 为什么经典：几乎是“连通块 DFS”的标准母题。

2. `HDU 1241 - Oil Deposits`
   - 类型：`DFS` / 连通块计数
   - 练什么：统计油田块数。
   - 重点：同样是 8 方向连通，输入多组数据。
   - 为什么经典：训练“多组输入 + visited 清空”。

3. `POJ 3984 - 迷宫问题`
   - 类型：`BFS` / 迷宫最短路
   - 练什么：从左上角到右下角，输出一条最短路径。
   - 重点：除了 `dist`，还要记录前驱坐标。
   - 为什么经典：BFS 不只求步数，还能还原路径。

4. `洛谷 P1443 - 马的遍历`
   - 类型：`BFS` / 无权最短路
   - 练什么：骑士走法到棋盘每个点的最少步数。
   - 重点：方向数组从 4 方向变成 8 种马步。
   - 为什么经典：训练“换方向数组，BFS 框架不变”。

### 考前优先

- 优先 1：`POJ 2386 - Lake Counting`
- 优先 2：`洛谷 P1443 - 马的遍历`
- 优先 3：`POJ 3984 - 迷宫问题`

## 2. 二分查找

### 必做题

1. `洛谷 P2249 - 查找`
   - 类型：二分 / 第一次出现位置
   - 练什么：找某个数在有序数组中第一次出现的位置。
   - 重点：`lower_bound` 的含义是第一个 `>= x`。
   - 为什么经典：非常贴合老师写的 `lower_bound`。

2. `POJ 2456 - Aggressive cows`
   - 类型：二分答案
   - 练什么：最大化最小距离。
   - 重点：不是在数组里找数，而是在答案空间里二分。
   - 为什么经典：二分答案入门母题。

3. `HDU 2141 - Can you find it?`
   - 类型：排序 + 二分
   - 练什么：先把两数组和排序，再二分查目标。
   - 重点：把复杂问题拆成可二分的有序数组。
   - 为什么经典：训练二分和预处理结合。

### 考前优先

- 优先 1：`洛谷 P2249 - 查找`
- 优先 2：`POJ 2456 - Aggressive cows`

## 3. 贪心

### 必做题

1. `HDU 2037 - 今年暑假不AC`
   - 类型：贪心 / 活动安排
   - 练什么：最多选择多少个不冲突节目。
   - 重点：按结束时间排序，能选就选。
   - 为什么经典：最适合考试的贪心模板题。

2. `POJ 1328 - Radar Installation`
   - 类型：贪心 / 区间选点
   - 练什么：每个岛转成雷达可放置区间，求最少雷达数。
   - 重点：按右端点排序。
   - 为什么经典：区间贪心经典题。

3. `洛谷 P1094 - 纪念品分组`
   - 类型：贪心 / 双指针
   - 练什么：两两配对，让组数最少。
   - 重点：最轻和最重能配就配，不能配就让最重单独一组。
   - 为什么经典：训练排序后的双指针贪心。

4. `POJ 3617 - Best Cow Line`
   - 类型：贪心 / 字符串双端选择
   - 练什么：每次从左端或右端取字符，使结果字典序最小。
   - 重点：相等时要继续向内比较。
   - 为什么经典：训练“局部选择前要处理平局”。

### 考前优先

- 优先 1：`HDU 2037 - 今年暑假不AC`
- 优先 2：`POJ 1328 - Radar Installation`
- 优先 3：`洛谷 P1094 - 纪念品分组`

## 4. 动态规划

### 4.1 最大子段和

1. `洛谷 P1115 - 最大子段和`
   - 类型：最大子段和
   - 练什么：只求最大连续子段和。
   - 重点：全负数时答案不能初始化为 0。
   - 为什么经典：适合先练基础板子。

2. `HDU 1003 - Max Sum`
   - 类型：最大子段和
   - 练什么：求最大连续子段和，并输出左右端点。
   - 重点：不仅维护最大和，还要维护起点和终点。
   - 为什么经典：最大子段和最标准题。

### 4.2 最长不降 / 最长上升子序列

1. `POJ 2533 - Longest Ordered Subsequence`
   - 类型：最长上升子序列
   - 练什么：`O(n^2)` 的 `LIS`。
   - 重点：严格上升用 `<`，不降用 `<=`。
   - 为什么经典：序列 DP 母题。

2. `洛谷 P1020 - 导弹拦截`
   - 类型：最长不上升子序列 / 最少系统数
   - 练什么：最长不上升和贪心优化思想。
   - 重点：题意容易绕，需要先做慢版理解。
   - 为什么经典：国内算法课常见经典题。

3. `HDU 1257 - 最少拦截系统`
   - 类型：贪心 + `LIS` 思想
   - 练什么：最少多少套系统拦截导弹。
   - 重点：和导弹拦截同类。
   - 为什么经典：训练“最长序列问题的变形”。

### 4.3 `0/1` 背包

1. `洛谷 P1048 - 采药`
   - 类型：`0/1` 背包
   - 练什么：每株草药只能采一次，时间是容量，价值是收益。
   - 重点：容量倒序。
   - 为什么经典：`0/1` 背包最适合入门题。

2. `HDU 2602 - Bone Collector`
   - 类型：`0/1` 背包
   - 练什么：容量内最大价值。
   - 重点：多组输入，数组清零。
   - 为什么经典：背包模板题。

3. `洛谷 P1060 - 开心的金明`
   - 类型：`0/1` 背包
   - 练什么：价值需要自己计算 `price * importance`。
   - 重点：题面会包装，但本质仍是背包。
   - 为什么经典：训练从题意抽象出重量和价值。

### 4.4 最长公共子序列

1. `HDU 1159 - Common Subsequence`
   - 类型：`LCS`
   - 练什么：两个字符串最长公共子序列。
   - 重点：二维 DP，字符相等取左上角加 1。
   - 为什么经典：`LCS` 标准模板题。

2. `POJ 1458 - Common Subsequence`
   - 类型：`LCS`
   - 练什么：和 HDU 1159 几乎同型。
   - 重点：多组字符串输入。
   - 为什么经典：用于巩固 `LCS` 板子。

3. `洛谷 P1439 - 最长公共子序列`
   - 类型：`LCS` 变形
   - 练什么：排列上的 `LCS` 可以转化为 `LIS`。
   - 重点：数据大时普通 `O(n^2)` 不够。
   - 为什么经典：适合进阶，不是第一轮必做。

### 动态规划考前优先

- 优先 1：`洛谷 P1115 - 最大子段和`
- 优先 2：`洛谷 P1048 - 采药`
- 优先 3：`HDU 2602 - Bone Collector`
- 优先 4：`HDU 1159 - Common Subsequence`
- 优先 5：`POJ 2533 - Longest Ordered Subsequence`

## 5. Floyd

### 必做题

1. `HDU 2544 - 最短路`
   - 类型：最短路基础题
   - 练什么：点数较小时可以用 `Floyd`。
   - 重点：初始化 `INF`，自己到自己为 0。
   - 为什么经典：最短路入门题。

2. `HDU 1874 - 畅通工程续`
   - 类型：最短路
   - 练什么：多源或单源最短路都可练。
   - 重点：有重边，建图取最小值。
   - 为什么经典：训练重边处理。

3. `POJ 1125 - Stockbroker Grapevine`
   - 类型：`Floyd` / 图中心
   - 练什么：求一个点到其他点最短路的最大值，再取最小。
   - 重点：`Floyd` 后要读懂题目要的统计量。
   - 为什么经典：不是只输出 `d[1][n]`，适合训练理解。

### 考前优先

- 优先 1：`HDU 2544 - 最短路`
- 优先 2：`HDU 1874 - 畅通工程续`

## 6. 最小生成树

### 必做题

1. `HDU 1233 - 还是畅通工程`
   - 类型：最小生成树
   - 练什么：`Kruskal` 标准板子。
   - 重点：边排序 + 并查集。
   - 为什么经典：`MST` 入门第一题。

2. `洛谷 P3366 - 模板 最小生成树`
   - 类型：最小生成树模板
   - 练什么：标准 `Kruskal`。
   - 重点：图不连通时输出 `orz`。
   - 为什么经典：适合直接检验板子。

3. `POJ 1287 - Networking`
   - 类型：最小生成树
   - 练什么：多组输入，求最小连接费用。
   - 重点：重复边也不怕，排序后并查集会处理。
   - 为什么经典：`MST` 基础巩固。

4. `POJ 1251 - Jungle Roads`
   - 类型：最小生成树
   - 练什么：字符点编号、建边、`Kruskal`。
   - 重点：输入格式稍复杂。
   - 为什么经典：训练非普通整数输入。

### 考前优先

- 优先 1：`HDU 1233 - 还是畅通工程`
- 优先 2：`洛谷 P3366 - 模板 最小生成树`
