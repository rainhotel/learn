# Algorithm Final Review Classic Problems

## 使用方式

- 这份题单尽量选择洛谷题，方便统一刷题和提交。
- 每个知识点先做“考前优先”，再做“加练”。
- 动态规划至少做 4 到 6 道，因为它最容易在状态定义、初始化、循环顺序上丢分。
- 所有代码默认按 `Dev-C++ / C++98` 写，不使用 `auto`、范围 `for`、`unordered_map`，正式板子也不依赖 `bits/stdc++.h`。

## 1. DFS / BFS

### 考前优先

1. `洛谷 P1596 - Lake Counting`
   - 类型：`DFS` / 连通块计数
   - 练什么：统计水洼数量。
   - 重点：8 个方向连通，不是普通 4 方向。
   - 为什么经典：搜索连通块母题，适合练 `visited` 和方向数组。

2. `洛谷 P1451 - 求细胞数量`
   - 类型：`DFS` / 连通块计数
   - 练什么：把相邻细胞搜成一整块。
   - 重点：判断哪些字符算细胞，哪些算背景。
   - 为什么经典：比 `P1596` 更贴近期末“数块数”题型。

3. `洛谷 P1443 - 马的遍历`
   - 类型：`BFS` / 无权最短路
   - 练什么：马从起点到棋盘每个点的最少步数。
   - 重点：方向数组从上下左右变成 8 种马步。
   - 为什么经典：训练“BFS 框架不变，只换移动方式”。

4. `洛谷 P1135 - 奇怪的电梯`
   - 类型：`BFS` / 最少操作次数
   - 练什么：每层楼可以上或下固定层数，求最少按几次按钮。
   - 重点：把楼层看成图上的点。
   - 为什么经典：帮助你从“迷宫 BFS”过渡到“状态 BFS”。

### 加练

1. `洛谷 P1162 - 填涂颜色`
   - 类型：`DFS/BFS` / 网格染色
   - 练什么：从外部背景开始搜索，区分内外区域。
   - 重点：不要直接搜内部，先从边界搜外部。

2. `洛谷 P1746 - 离开中山路`
   - 类型：`BFS` / 迷宫最短路
   - 练什么：网格起点到终点的最短步数。
   - 重点：`dist` 初始化和越界判断。

## 2. 二分查找

### 考前优先

1. `洛谷 P2249 - 查找`
   - 类型：二分 / 第一次出现位置
   - 练什么：找某个数第一次出现的位置。
   - 重点：`lower_bound` 是第一个 `>= x` 的位置。
   - 为什么经典：非常贴合老师写的 `lower_bound / upper_bound`。

2. `洛谷 P1102 - A-B 数对`
   - 类型：排序 + 二分
   - 练什么：统计满足 `A - B = C` 的数对数量。
   - 重点：用 `lower_bound` 和 `upper_bound` 统计某个值出现次数。
   - 为什么经典：把二分边界真正用到计数里。

3. `洛谷 P2678 - 跳石头`
   - 类型：二分答案
   - 练什么：最大化最短跳跃距离。
   - 重点：判定函数 `check(x)` 怎么写。
   - 为什么经典：二分答案经典题。

### 加练

1. `洛谷 P1182 - 数列分段 Section II`
   - 类型：二分答案
   - 练什么：最小化每段和的最大值。
   - 重点：答案越大越容易分段，具有单调性。

2. `洛谷 P1873 - 砍树`
   - 类型：二分答案
   - 练什么：求最高的砍树高度。
   - 重点：注意 `long long`。

## 3. 贪心

### 考前优先

1. `洛谷 P1803 - 凌乱的yyy / 线段覆盖`
   - 类型：贪心 / 活动安排
   - 练什么：最多选择多少个不重叠区间。
   - 重点：按右端点从小到大排序。
   - 为什么经典：最贴近“区间贪心模板题”。

2. `洛谷 P1094 - 纪念品分组`
   - 类型：贪心 / 排序 + 双指针
   - 练什么：两两配对，让组数最少。
   - 重点：最轻和最重能配就配，不能配就让最重单独一组。
   - 为什么经典：简单但很考贪心判断。

3. `洛谷 P1223 - 排队接水`
   - 类型：贪心 / 排序
   - 练什么：让平均等待时间最小。
   - 重点：耗时短的人排前面。
   - 为什么经典：训练“排序依据来自目标函数”。

### 加练

1. `洛谷 P1208 - 混合牛奶`
   - 类型：贪心 / 单价排序
   - 练什么：从便宜到贵购买，满足需求。
   - 重点：排序后逐个取。

2. `洛谷 P4995 - 跳跳！`
   - 类型：贪心 / 排序后构造
   - 练什么：通过取极值让能量和尽量大。
   - 重点：理解“尽量制造高度差”。

## 4. 动态规划

### 4.1 最大子段和

#### 考前优先

1. `洛谷 P1115 - 最大子段和`
   - 类型：最大子段和
   - 练什么：求最大连续子段和。
   - 重点：全负数时答案不能初始化为 0。
   - 为什么经典：最大子段和基础模板题。

#### 加练

1. `洛谷 P1719 - 最大加权矩形`
   - 类型：二维最大子段和
   - 练什么：把二维问题压缩成一维最大子段和。
   - 重点：进阶题，第一轮可以先跳过。

### 4.2 最长不降 / 最长上升子序列

#### 考前优先

1. `洛谷 B3637 - 最长上升子序列`
   - 类型：`LIS`
   - 练什么：`O(n^2)` 的最长上升子序列。
   - 重点：严格上升用 `<`。
   - 为什么经典：适合 Dev-C++ 手写基础序列 DP。

2. `洛谷 P1020 - 导弹拦截`
   - 类型：最长不上升子序列 / 最少系统数
   - 练什么：最长不上升和序列贪心思想。
   - 重点：题意容易绕，先写慢版理解。
   - 为什么经典：国内算法课和考试常见题。

3. `洛谷 P1091 - 合唱队形`
   - 类型：`LIS` + 反向 `LIS`
   - 练什么：从左到右、从右到左各做一次 DP。
   - 重点：中间同学被两边共同计算，需要减 1。
   - 为什么经典：训练序列 DP 的组合变形。

#### 加练

1. `洛谷 P1439 - 最长公共子序列`
   - 类型：`LCS` 转 `LIS`
   - 练什么：排列的公共子序列可以转成位置序列的 `LIS`。
   - 重点：进阶题，不是第一轮必做。

### 4.3 `0/1` 背包

#### 考前优先

1. `洛谷 P1048 - 采药`
   - 类型：`0/1` 背包
   - 练什么：时间是容量，草药价值是收益。
   - 重点：每株草药只能采一次，容量倒序。
   - 为什么经典：`0/1` 背包最适合入门题。

2. `洛谷 P1060 - 开心的金明`
   - 类型：`0/1` 背包
   - 练什么：价值要先计算为 `价格 * 重要度`。
   - 重点：从题面抽象出重量和价值。
   - 为什么经典：背包常见包装题。

3. `洛谷 P1164 - 小A点菜`
   - 类型：背包计数
   - 练什么：求刚好花完钱的方案数。
   - 重点：`dp[j] += dp[j - w[i]]`，不是取 `max`。
   - 为什么经典：训练“背包不一定都是最大价值”。

#### 加练

1. `洛谷 P1616 - 疯狂的采药`
   - 类型：完全背包
   - 练什么：每种草药可以采无限次。
   - 重点：容量正序，和 `0/1` 背包方向相反。

2. `洛谷 P1802 - 5倍经验日`
   - 类型：背包变形
   - 练什么：每个选择都有输和赢两种收益。
   - 重点：先理解题意，再套状态。

### 4.4 最长公共子序列

#### 考前优先

1. `洛谷 P1439 - 最长公共子序列`
   - 类型：`LCS` 变形
   - 练什么：两个排列的 `LCS` 转成 `LIS`。
   - 重点：这题数据大，普通二维 `LCS` 会超时。
   - 为什么经典：洛谷上很经典，但比普通 `LCS` 难。

2. `洛谷 P2758 - 编辑距离`
   - 类型：双序列 DP
   - 练什么：两个字符串之间的插入、删除、替换。
   - 重点：和 `LCS` 一样是二维前缀状态。
   - 为什么推荐：洛谷上适合练二维字符串 DP。

#### 普通 LCS 备选

- 洛谷上标准裸 `LCS` 题不如 HDU/POJ 常见。如果你只想练最基础二维 `LCS`，仍建议备选：
  - `HDU 1159 - Common Subsequence`
  - `POJ 1458 - Common Subsequence`
- 这两个题非常适合练期末板子，写法完全符合 `Dev-C++ / C++98`。

## 5. Floyd

### 考前优先

1. `洛谷 P2910 - [USACO08OPEN] Clear And Present Danger S`
   - 类型：`Floyd`
   - 练什么：先求任意两点最短路，再按给定路线累加。
   - 重点：`Floyd` 后不一定直接输出 `d[1][n]`。
   - 为什么经典：非常适合练全源最短路。

2. `洛谷 P1119 - 灾后重建`
   - 类型：`Floyd` 变形
   - 练什么：按时间逐步开放节点。
   - 重点：每次询问前只把可用节点加入中转。
   - 为什么经典：`Floyd` 的经典提高题。

### 加练

1. `洛谷 B3647 - 【模板】Floyd`
   - 类型：`Floyd` 模板
   - 练什么：标准三重循环。
   - 重点：适合先手写板子。

2. `洛谷 P6464 - 传送门`
   - 类型：最短路 / Floyd 思想
   - 练什么：读题建图和多点最短路。
   - 重点：难度略高，可后做。

## 6. 最小生成树

### 考前优先

1. `洛谷 P3366 - 【模板】最小生成树`
   - 类型：最小生成树模板
   - 练什么：标准 `Kruskal`。
   - 重点：图不连通时输出 `orz`。
   - 为什么经典：直接检验 MST 板子。

2. `洛谷 P1546 - 最短网络 Agri-Net`
   - 类型：最小生成树
   - 练什么：邻接矩阵输入，求最小连接费用。
   - 重点：矩阵转边集，或直接用 `Prim`。
   - 为什么经典：适合考试图论基础题。

3. `洛谷 P2330 - 繁忙的都市`
   - 类型：最小生成树
   - 练什么：输出选边数量和最大边权。
   - 重点：Kruskal 选到 `n - 1` 条边时，最后一条边权就是答案之一。
   - 为什么经典：训练 MST 输出不只总权值。

### 加练

1. `洛谷 P2872 - [USACO07DEC] Building Roads S`
   - 类型：最小生成树 / 坐标建边
   - 练什么：已有道路权值为 0，其他道路按距离建边。
   - 重点：建图比 Kruskal 本身更重要。

2. `洛谷 P1194 - 买礼物`
   - 类型：最小生成树变形
   - 练什么：加入虚拟点处理直接购买。
   - 重点：适合进阶。
