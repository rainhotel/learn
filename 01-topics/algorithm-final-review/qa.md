# Algorithm Final Review QA

## 高频误区

### `bits/stdc++.h` 能不能写

- 如果老师只看思想，不严格卡标准，通常能写。
- 但你现在要求按 `C++98` 准备，所以默认不要把它当正式考试板子。

### `DFS` 和 `BFS` 到底怎么选

- 统计连通块、搜所有状态：优先 `DFS`。
- 最少步数、无权最短路：优先 `BFS`。

### `lower_bound` 和 `upper_bound` 老是混

- `lower_bound(x)`：第一个 `>= x`
- `upper_bound(x)`：第一个 `> x`

### 最长不降子序列和最长上升子序列差在哪

- 不降：允许相等，所以条件是 `a[j] <= a[i]`
- 上升：不允许相等，所以条件是 `a[j] < a[i]`

### 背包为什么一定要倒序

- 因为 `0/1` 背包每件物品只能用一次。
- 倒序才能保证本轮更新时不会重复使用当前物品。

### 最长公共子序列和最长公共子串差在哪

- 子序列可以不连续。
- 子串必须连续。
- 这两个题的状态转移完全不同，考试时别混。

### `Floyd` 的 `INF` 为什么不能乱写小

- 如果 `INF` 太小，真实路径可能会被误判成不可达。
- 常见安全写法是 `0x3f3f3f3f`。

### 最小生成树做完以后还要检查什么

- 检查是否真的选了 `n - 1` 条边。
- 如果没选满，说明图不连通，不能生成完整生成树。
