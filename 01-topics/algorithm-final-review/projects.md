# Algorithm Final Review Projects

## Practice Set A - 每类 1 道代表题

1. `DFS`：给一个字符网格，`#` 表示障碍，求有多少个连通块。
2. `BFS`：迷宫四联通，从 `S` 到 `T` 的最少步数。
3. 二分：有序数组中统计某个数 `x` 出现了多少次。
4. 贪心：给若干区间，求最多能选多少个互不重叠区间。
5. 最大子段和：给整数序列，求连续子段最大和。
6. 最长不降子序列：求最长长度。
7. `0/1` 背包：容量为 `m`，求最大价值。
8. 最长公共子序列：给两个字符串，求 `LCS` 长度。
9. `Floyd`：多次询问任意两点最短路。
10. 最小生成树：给无向图边集，求最小生成树权值和。

## Practice Set B - 小改题

1. `DFS` 连通块改成统计每个连通块大小。
2. `BFS` 迷宫改成带多个起点同时扩散。
3. 二分统计出现次数改成查第一个大于 `x` 的位置。
4. 区间选择改成区间覆盖。
5. 最大子段和改成输出最大和对应的左右端点。
6. 最长不降子序列改成最长严格上升子序列。
7. `0/1` 背包改成完全背包。
8. `LCS` 改成最长公共子串。
9. `Floyd` 改成带重边输入。
10. 最小生成树改成判断图是否连通。

## Practice Set C - 限时模拟

- 30 分钟：
  - 手写 `DFS`、二分、最大子段和
- 45 分钟：
  - 手写 `BFS`、`0/1` 背包、`Floyd`
- 60 分钟：
  - 做 1 道搜索、1 道 DP、1 道图论
