# Algorithm Final Review

## Goal

- 把老师圈出的算法期末考点整理成一套可直接复习的专题。
- 按 `C++98` 风格准备稳定可默写的板子，不依赖 `bits/stdc++.h`。
- 每个考点都配一类代表题和几类相似变形，方便考前套题。

## Scope

- 覆盖图片里的 5 类重点：`DFS/BFS`、二分查找、贪心、动态规划、图论。
- 动态规划重点整理：最大子段和、最长不降子序列、`0/1` 背包、最长公共子序列。
- 图论重点整理：`Floyd` 全源最短路、最小生成树。
- 新增考前扩展板子：`STL` 常用语法、`pair/make_pair`、非 `vector` 搜索、完全背包、`Dijkstra`、`Prim`、二分答案。
- 暂时不展开拓扑排序、线段树等不在当前要求里的内容。

## Outcome

- 能在纸上默写出 8 到 10 个基础板子。
- 能快速判断一道题更像搜索、二分、贪心、DP 还是图论。
- 能把“原题”改成“小改题”时知道该改哪一行状态或判断。
- 能在考前按专题刷一轮代表题。
