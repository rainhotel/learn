## 一、存储过程

### 1. 无参数存储过程 Stu_Query

**功能**：从 3 个表查询，返回学号、姓名、专业名、课程名、成绩。

```sql
USE StudentCourse
GO

IF EXISTS (SELECT name FROM sysobjects WHERE name = 'Stu_Query' AND type = 'P')
    DROP PROCEDURE Stu_Query
GO

CREATE PROCEDURE Stu_Query
AS
    SELECT a.学号, 姓名, 专业名, 课程名, 成绩
    FROM Student a
    LEFT JOIN StuCourse b ON a.学号 = b.学号
    LEFT JOIN Course c ON b.课程号 = c.课程号
GO

-- 执行
EXEC Stu_Query
GO
```

**期望**：输出所有学生的选课信息，未选课的学生课程名和成绩显示 NULL。

### 2. 带参数存储过程 Query_Stu

**功能**：输入学生姓名和课程名，查询该生该课的成绩。

```sql
USE StudentCourse
GO

IF EXISTS (SELECT name FROM sysobjects WHERE name = 'Query_Stu' AND type = 'P')
    DROP PROCEDURE Query_Stu
GO

CREATE PROCEDURE Query_Stu
    @xm    CHAR(12),
    @kcmc  CHAR(40)
AS
    SELECT a.学号, 姓名, 课程名, 成绩
    FROM Student a
    LEFT JOIN StuCourse b ON a.学号 = b.学号
    LEFT JOIN Course c ON b.课程号 = c.课程号
    WHERE a.姓名 = @xm AND c.课程名 = @kcmc
GO

EXEC Query_Stu '王强', '数据库系统'
GO
```

**期望**：输出 '丁一平' 选修 '程序设计基础' 的成绩记录。若库中无此数据则返回空结果集。

### 3. 带参数存储过程 Proc_Student

**功能**：根据学号判断，不存在则插入，存在则更新。

```sql
USE StudentCourse
GO

IF EXISTS (SELECT name FROM sysobjects WHERE name = 'Proc_Student' AND type = 'P')
    DROP PROCEDURE Proc_Student
GO

CREATE PROCEDURE Proc_Student
    @xh    CHAR(6),
    @xm    CHAR(12),
    @zym   VARCHAR(20),
    @xb    CHAR(2),
    @cssj  DATETIME,
    @zxf   INT,
    @bz    TEXT
AS
    DECLARE @cn INT
    SELECT @cn = COUNT(*) FROM Student WHERE 学号 = @xh
    IF @cn = 0
    BEGIN
        INSERT INTO Student(学号, 姓名, 专业名, 性别, 出生时间, 总学分, 备注)
        VALUES(@xh, @xm, @zym, @xb, @cssj, @zxf, @bz)
    END
    ELSE
    BEGIN
        UPDATE Student
        SET 姓名 = @xm, 专业名 = @zym, 性别 = @xb,
            出生时间 = @cssj, 总学分 = @zxf, 备注 = @bz
        WHERE 学号 = @xh
    END
GO

-- 测试：执行存储过程（学号自行调整）
EXEC Proc_Student '100001', '新同学', '计算机科学与技术', '男', '2001-05-20', 18, '存储过程测试'
GO

-- 查看执行后的变化
SELECT * FROM Student
GO
```

**期望**：若 `100001` 不存在，Student 表新增一行；再次执行则更新该行。

### 4. 存储过程 Stu_course（实验9 思考与练习）

**功能**：根据学号查询该生所修课程的课程号、课程名。

```sql
USE StudentCourse
GO

IF EXISTS (SELECT name FROM sysobjects WHERE name = 'Stu_course' AND type = 'P')
    DROP PROCEDURE Stu_course
GO

CREATE PROCEDURE Stu_course
    @sno CHAR(6)
AS
    SELECT c.课程号, c.课程名, sc.成绩
    FROM StuCourse sc
    JOIN Course c ON sc.课程号 = c.课程号
    WHERE sc.学号 = @sno
GO

-- 执行（学号需根据实际数据调整）
EXEC Stu_course '070101'
GO
```

**期望**：输出该学生所有选修课程的课程号、课程名和成绩。

### 5. 存储过程 Stu_course1（实验9 思考与练习）

**功能**：根据学号统计该生的平均成绩和选课门数。

```sql
USE StudentCourse
GO

IF EXISTS (SELECT name FROM sysobjects WHERE name = 'Stu_course1' AND type = 'P')
    DROP PROCEDURE Stu_course1
GO

CREATE PROCEDURE Stu_course1
    @sno CHAR(6)
AS
    SELECT AVG(CAST(成绩 AS DECIMAL(5,2))) AS 平均成绩,
           COUNT(*) AS 选课门数
    FROM StuCourse
    WHERE 学号 = @sno
GO

-- 执行
EXEC Stu_course1 '070101'
GO
```

**期望**：输出该生的平均成绩和选课门数。

## 二、触发器

### 1. 触发器 Ctrig：学分不能小于 2

> 这是实验8 思考与练习3：课程的学分若小于 2，自动改为 2。

#### ① 定义触发器

```sql
USE StudentCourse
GO

IF EXISTS (SELECT name FROM sysobjects WHERE name = 'Ctrig' AND type = 'TR')
    DROP TRIGGER Ctrig
GO

CREATE TRIGGER Ctrig ON Course
AFTER INSERT, UPDATE
AS
BEGIN
    SET NOCOUNT ON

    UPDATE c
    SET 学分 = 2
    FROM Course c
    JOIN inserted i ON c.课程号 = i.课程号
    WHERE c.学分 < 2
END
GO
```

#### ② 验证触发器

**验证1：插入学分=1 的课程，触发器自动改为 2**

```sql
USE StudentCourse
GO

-- 先查看执行前 Course 表数据
SELECT * FROM Course
GO

-- 插入学分=1 的课程
INSERT INTO Course (课程号, 课程名, 开课学期, 学时, 学分)
VALUES ('C010', '测试课程-学分1', 1, 32, 1)
GO

-- 查看结果（学分应被触发器自动改为2）
SELECT * FROM Course WHERE 课程号 = 'C010'
GO
```

**验证2：更新已有课程学分为 1，触发器自动改为 2**

```sql
USE StudentCourse
GO

-- 更新学分=1（应被触发器改为2）
UPDATE Course SET 学分 = 1 WHERE 课程号 = 'C010'
GO

-- 查看结果
SELECT * FROM Course WHERE 课程号 = 'C010'
GO
```

**验证3：插入学分=3（满足条件，触发器不修改）**

```sql
USE StudentCourse
GO

INSERT INTO Course (课程号, 课程名, 开课学期, 学时, 学分)
VALUES ('C011', '测试课程-学分3', 2, 48, 3)
GO

SELECT * FROM Course WHERE 课程号 = 'C011'
GO
```

**清理测试数据：**

```sql
DELETE FROM Course WHERE 课程号 IN ('C010', 'C011')
GO
```

#### ③ 执行结果

| 操作 | 期望 |
|------|------|
| INSERT 学分=1 | **成功**，学分自动变为 `2` |
| UPDATE 学分=1 | **成功**，学分自动变为 `2` |
| INSERT 学分=3 | **成功**，学分保持 `3`（不触发） |

### 2. 触发器 SC_trig（教材附录版）

> 实验8 附录A 内容3：向 StuCourse 插入记录时，检查学号是否在 Student 中存在，若**不存在**则取消操作。

```sql
USE StudentCourse
GO

IF EXISTS (SELECT name FROM sysobjects WHERE name = 'SC_trig' AND type = 'TR')
    DROP TRIGGER SC_trig
GO

CREATE TRIGGER SC_trig ON StuCourse
FOR INSERT
AS
    IF ((SELECT a.学号 FROM inserted a) NOT IN (SELECT b.学号 FROM Student b))
    BEGIN
        RAISERROR('插入操作违背数据的一致性', 16, 1)
        ROLLBACK TRANSACTION
    END
GO

-- 测试：插入不存在的学号（应被拒绝）
INSERT INTO StuCourse VALUES ('070110', '2001', 70)
GO

-- 测试：插入存在的学号（应成功，替换为你库中实际存在的学号和课程号）
INSERT INTO StuCourse VALUES ('070101', '1001', 85)
GO
```

**期望**：

| 操作 | 期望 |
|------|------|
| 插入不存在的学号 `070110` | **失败**，`插入操作违背数据的一致性` |
| 插入存在的学号 `070101` | **成功** |

> 注意：教材版触发器的逻辑是 `NOT IN`（学号不存在才拒绝），与实验9的 `IN` 版本（学号存在才拒绝）逻辑相反。根据实际教材要求选用。
