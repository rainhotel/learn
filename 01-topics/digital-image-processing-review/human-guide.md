# 数字图像处理考前导读

这门课复习最重要的不是死背公式，而是把每类题目对应到固定的方法。

先记住四条主线：

- 图像怎么表示：像素、灰度、采样、量化、动态范围。
- 图像怎么增强：空域变换、直方图、滤波。
- 图像怎么修复：噪声、模糊、复原模型。
- 图像怎么分割：阈值、边缘、区域、颜色。

考试里最容易丢分的地方：

- 公式会背但不会解释适用条件。
- 手算题漏写邻域、模板、加权过程和取整规则。
- 中值滤波只写结果，不写排序过程。
- MATLAB 题只写函数名，不写处理逻辑。

复习顺序建议：

1. 先过 `notes.md` 里的基础概念。
2. 再重点背“空域增强”和“频域/复原”。
3. 最后练“题型模板”和“常见坑”。
