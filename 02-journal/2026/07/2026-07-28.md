# Study Log - 2026-07-28

## Today's Focus

- 为 Agent 与后端面试准备 Redis Cluster 的哈希槽。

## What I Learned

- 哈希槽是 Redis Cluster 的逻辑分片单位，不是 Redis Hash 数据结构。
- Redis Cluster 固定有 16384 个槽，使用 `CRC16(key) % 16384` 把 key 映射到槽，再路由到负责该槽的主节点。
- 槽是扩缩容时的迁移单位；`MOVED` 表示客户端应刷新槽位映射，`ASK` 表示迁移期间的一次性临时路由。
- 多 key 操作要求同槽，可以使用 `{...}` hash tag，但过度使用可能造成热槽。
