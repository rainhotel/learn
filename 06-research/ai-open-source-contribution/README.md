# AI Open Source Contribution Research

## 研究目标

为一个中国学生筛选 GitHub 上 star 数较高、AI 相关、公开欢迎外部贡献者，并且适合作为开源贡献起点的项目。

## 边界

- 不按贡献者国籍做判断。公开开源项目通常接受全球贡献者。
- 这里的“适合中国学生”主要指：
  - 有中文资料、中文社区或中国维护者背景；
  - 有清晰贡献入口；
  - 有适合新手的小任务、文档、示例、测试、复现类工作；
  - 项目仍然活跃维护。
- star 数只作为热度信号，不作为唯一标准。

## 当前结论

优先关注这些项目：

1. `langgenius/dify`
2. `milvus-io/milvus`
3. `hiyouga/LlamaFactory`
4. `PaddlePaddle/PaddleOCR`
5. `infiniflow/ragflow`
6. `open-webui/open-webui`
7. `FlowiseAI/Flowise`
8. `datawhalechina/hello-agents`

更高阶但值得长期关注：

- `huggingface/transformers`
- `langchain-ai/langchain`
- `run-llama/llama_index`
- `vllm-project/vllm`
- `OpenHands/OpenHands`
- `browser-use/browser-use`
