# 给人的研究摘要

## 最推荐的起步选择

### Dify

- GitHub: https://github.com/langgenius/dify
- star: 147k+
- 技术栈: TypeScript, Python
- 适合原因: AI 应用平台，中文用户多，产品形态清晰，文档、UI、集成、示例都有贡献空间。
- 新手入口: 文档修复、翻译、前端小 bug、插件或 provider 示例、issue 复现。

### Milvus

- GitHub: https://github.com/milvus-io/milvus
- star: 45k+
- 技术栈: Go, C++, Python 周边
- 适合原因: 向量数据库，AI 基础设施方向，社区成熟，也有中文生态。
- 新手入口: 文档、SDK 示例、测试、good first issue。

### LlamaFactory

- GitHub: https://github.com/hiyouga/LlamaFactory
- star: 72k+
- 技术栈: Python
- 适合原因: 大模型微调工具，中文学习者友好，项目主题和学生学习路径高度匹配。
- 新手入口: README/文档、训练示例、模型适配说明、bug 复现。

### PaddleOCR

- GitHub: https://github.com/PaddlePaddle/PaddleOCR
- star: 84k+
- 技术栈: Python
- 适合原因: OCR 和文档智能方向成熟，中文资料丰富，适合从 demo、文档、样例和模型使用问题切入。
- 新手入口: 示例修复、文档补充、部署教程、问题复现。

### RAGFlow

- GitHub: https://github.com/infiniflow/ragflow
- star: 83k+
- 技术栈: Go, Python, TypeScript
- 适合原因: RAG 应用方向热门，中文背景较强，项目仍活跃。
- 新手入口: 文档、部署问题复现、连接器、前端体验问题。

## 不建议第一步就冲的项目

- `huggingface/transformers`: 影响力极大，但贡献门槛较高，适合等你熟悉测试、模型结构和贡献流程后再上。
- `vllm-project/vllm`: 高价值，但偏系统和性能，适合有 CUDA、推理优化或后端经验后挑战。
- `pytorch/pytorch` / `tensorflow/tensorflow`: star 很高，但作为第一个 PR 往往太重。

## 第一周行动

1. 第 1 天: 从 Dify、Milvus、LlamaFactory 里选一个，跑通本地开发环境。
2. 第 2 天: 阅读 `README`、贡献指南、issue 标签，记录 3 个你能理解的问题。
3. 第 3 天: 选择一个文档或复现类 issue，在 issue 下留言说明你想尝试。
4. 第 4 天: 做最小修改，不追求大功能。
5. 第 5 天: 提交 PR，标题清楚，描述包含动机、修改内容、验证方式。
