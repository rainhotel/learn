# 岗位研究导读

## 为什么研究 JD

课程不能只按技术热词排课。JD 研究用于检查：Java 后端、Agent 应用后端、平台工程和先进制造岗位真实反复要求哪些能力；哪些技能只是加分项；哪些项目证据能够在面试中被追问。

## 四类样本

1. Java 后端：Java/Spring、MySQL、Redis、MQ、并发、分布式、测试和排障。
2. Agent 后端：LLM API、RAG、Embedding、向量库、Tool、工作流、评测和安全。
3. 平台工程：Docker/Kubernetes、CI/CD、可观测性、容量和多机故障。
4. 制造数字化：设备/工单/质量/供应链数据、系统集成、权限、可追溯和长期运维。

## 研究结果如何进入课程

- 高频必需项进入学习主线和周测。
- 高频加分项进入项目扩展和选修实验。
- 只出现一次的技术先记录，不立即改变主线。
- 每个关键词都要映射到章节、项目任务和可展示证据。
