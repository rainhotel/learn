# 研究过程笔记

## 采样流程

1. 先按岗位族和城市设置过滤条件。
2. 从官方招聘入口搜索 Java backend、AI application、Agent、RAG、platform、digital manufacturing 等词。
3. 打开岗位详情页，记录岗位 ID、发布日期/更新时间和正文，不复制无关隐私。
4. 将职责、必需、加分和业务域拆成原子能力。
5. 去重同一岗位在多个平台的转载。
6. 对能力编码：`java`、`spring`、`mysql`、`redis`、`mq`、`distributed`、`docker`、`k8s`、`observability`、`llm`、`rag`、`agent`、`evaluation`、`security`、`manufacturing-domain`。
7. 统计每类出现次数，并保留反例和版本变化。

## 分析规则

- “熟悉/了解”不等于“负责生产”。
- “有 AI 项目经验”要拆成模型调用、RAG、评测、工具、安全和后端工程。
- “高并发/高可用”必须继续寻找容量、SLA、数据一致性或故障职责证据。
- “全栈”要拆成前端、API、部署、测试和 AI 辅助边界，不作为单一技术。
