# 研究结论

## 当前结论（低置信度/框架层）

- Java 后端主线仍应覆盖并发、MySQL、Redis、消息、事务、可观测性和分布式。
- Agent 后端不能只学 prompt，应覆盖 RAG、Tool、状态机、权限、幂等、评测、部署和故障恢复。
- 先进制造岗位的课程映射需要额外关注业务数据集成、可追溯、权限、长期运行和设备/工单上下文。

这些是课程设计假设，不是 2026 实时 JD 统计结论。
