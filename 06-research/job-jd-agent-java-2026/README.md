# 2026 Java 后端、Agent 与先进制造岗位研究

## 研究目标

为暑期求职课程建立可复核的岗位证据：

- Java 后端开发与分布式后端。
- Agent/AI 应用后端、RAG、Tool/Workflow Runtime。
- 平台工程、容器、可观测性和多机分布式。
- 先进制造数字化、工业互联网、供应链/质量系统后端。

## 研究边界

- 只把访问当天页面中出现的要求写成当前证据。
- 每条样本保存 URL、抓取日期、城市、经验、职责、必需/加分关键词和原文摘录。
- 招聘官网优先，Boss/猎聘/智联等平台用于发现岗位，不把平台摘要当最终证据。
- 不采集个人隐私、登录凭证或需要绕过访问控制的内容。
