# 结论、证据链与建议

## 结论一：定位应进一步收窄

推荐定位：

> Agent 平台/应用后端工程师：以 Java 和服务端系统能力为主，具备 Agent Runtime、工具调用、记忆、插件与 AI 辅助全栈交付经验。

证据：字节、腾讯、小米、海尔样本都同时要求 AI/Agent 概念与传统服务端能力，而不是只会 Prompt 或框架调用。

## 结论二：你的实习经历具有直接岗位匹配

Xpert 经历中的 Memory、Plugin Runtime、MCP、编程代理、IM 接入、身份绑定和多实例队列，与岗位中的 Memory、Tool Calling、MCP、Skill、服务接入和高可用高度重合。

问题不在于再造一段虚构经历，而在于将现有经历压缩成 3 个可深入答辩的工程故事，并补充公开项目证据。

## 结论三：Java 并发与后端基础是跨行业共同门槛

腾讯强调高并发高可用，字节强调分布式系统和数据库/中间件，海尔直接要求 Java 多线程、线程池和 Spring 底层机制。Java 并发学习应保留为暑期最高优先级之一。

## 结论四：AI 辅助全栈应通过“可验证交付”证明

小米 MiMo 岗位明确要求前后端任务、单测、接口测试、端到端测试、视觉回归、浏览器自动化、沙箱和 CI/CD。证明全栈能力的最佳方式不是技能栏增加 React，而是提供一个从 API 到页面、测试、部署都可复现的 Agent 项目。

## 学习计划调整

### 时间比例

- Java/后端基础与系统设计：40%
- Agent Runtime 项目：35%
- 算法：15%
- 前端、自动化测试与简历表达：10%

### 项目必须新增的验收项

- 一个最小但完整的前端运行控制台。
- Tool/Skill 注册与权限模型。
- Memory 或 Checkpoint 恢复。
- 单元、接口和端到端测试。
- 有界并发、超时、取消、重试和幂等。
- 执行 trace、成功率、P95 和失败分类。
- 使用 AI 辅助开发时保留任务拆解、验证和人工决策记录。

## 投递策略

### 近期

你是 2028 届，应优先找日常实习、长期实习和明确覆盖 2028 届的岗位。不要只盯当前 2027 届暑期实习。

### 未来 6-12 个月

- 第一梯队：字节、百度、阿里、小米等 Agent 服务端/平台实习。
- 第二梯队：MiniMax、智谱、月之暗面等模型公司的 Agent 工程岗位。
- 制造业梯队：华为、海尔、美的、西门子、博世、宁德时代的 AI 应用、工业软件和数字化研发岗位。

- Boss 详情页受登录和反自动化限制，部分岗位只获得搜索索引摘要。
- 职位随时可能关闭；投递前必须再次打开企业官网确认。
- 当前样本偏一线城市和社招能力模型，后续应补充 2028 届实习岗位。
