# 岗位要求整理

## 高频能力矩阵

| 能力 | 互联网 Agent 岗 | 传统后端岗 | 先进制造 AI 岗 | 当前匹配度 |
|---|---|---|---|---|
| 数据结构与算法 | 高 | 高 | 中高 | 中 |
| Java/Go/Python 服务端 | 高 | 高 | 高 | Java 中，TS/Python 较强 |
| 数据库/缓存/消息队列 | 高 | 高 | 高 | 中 |
| 并发、高可用、低延迟 | 高 | 高 | 高 | 有经历，证据待补 |
| RAG/工具调用/MCP | 高 | 低中 | 中高 | 高 |
| Agent 规划与记忆 | 高 | 低 | 中 | 高 |
| 评测、测试、可观测性 | 高 | 高 | 中高 | 中低 |
| 前后端完整交付 | 中高 | 中 | 高 | 中高 |
| 容器化与部署 | 高 | 高 | 高 | 中 |
| 模型训练/SFT/RL | 算法岗高，工程岗加分 | 低 | 中 | 低 |

## 高频关键词

- Agent：Planning、Tool Calling、Memory、RAG、MCP、Skill、Multi-Agent、Agentic Eval。
- 后端：高并发、高可用、低延迟、数据库、缓存、消息队列、线程池、容器化。
- 工程全栈：API、权限、数据库、测试、浏览器自动化、沙箱、CI/CD、可维护性。
- 制造业融合：AI 模型集成、业务系统打通、Java/Spring、工业/电商/设备场景理解。

## 岗位路线区分

### Agent 算法路线

需要 Transformer、SFT、RL、PyTorch、论文复现和评测研究。阿里和美团的样本明显偏此路线，通常更偏硕博。

### Agent 工程路线

需要 Agent Runtime、工具/知识库、服务端工程、状态与错误治理。字节服务端、腾讯后台和小米框架最有代表性，与你更匹配。

### AI 应用全栈路线

需要把复杂业务变成真实工程任务，覆盖前端、后端、自动测试、沙箱与部署。小米 MiMo 样本是最清晰的目标画像。

## 不应误读的信号

- LangChain/LangGraph 只是工具，岗位真正考察的是运行时、系统设计和业务落地。
- “全栈”不等于平均分配前后端学习时间，主干仍应是后端与系统工程。
- 算法岗中的 SFT/RL 不能直接替代后端工程能力，也不是当前暑假的最高优先级。
- 社招岗位要求不能原样塞入学生简历，但可以用于规划未来能力上限。
