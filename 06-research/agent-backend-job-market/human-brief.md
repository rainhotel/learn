# 岗位研究摘要

## 最值得关注的三类岗位

### 1. Agent 服务端/平台研发

代表：字节 AI Agent 服务端实习、腾讯微信 Agent 后台、小米 Agent 框架。

核心工作不是简单调用模型，而是设计任务规划、工具调用、记忆、RAG、MCP、状态管理、高可用与性能治理。

### 2. AI 应用后端

代表：百度千帆 AppBuilder 后端、海尔 AI 应用后端、京东大模型应用后端。

核心要求是把模型稳定接入业务系统，仍然重视 Java/Go/Python、数据库、缓存、消息队列、线程池、容器化和运维。

### 3. Agent 工程全栈

代表：小米 MiMo Agent 全栈研发。

这里的“全栈”不是追求精通所有 UI 技术，而是能理解前端、API、数据库、测试、浏览器自动化、沙箱和部署，把复杂任务转成可运行、可评测的工程环境。

## 对你的判断

你的 Xpert 实习已经覆盖 Memory、插件运行时、MCP、外部 IM 和身份接入，与 Agent 服务端/平台研发高度匹配。短板主要是：

- Java 作为主语言的可信深度不足。
- 数据结构与算法仍是大厂实习岗的硬门槛。
- 缺少可公开的 Agent 项目、自动测试、压测和评测结果。
- 简历中的模块很多，但“个人解决了什么难题”表达不够集中。

## 当前优先关注

优先研究和准备：

1. 字节 AI Agent 服务端/应用开发实习岗。
2. 百度 Agent 平台后端实习岗。
3. 小米 MiMo Agent 全栈岗位所代表的长期能力模型。
4. 海尔 AI 应用后端所代表的制造业 Java + AI 融合岗位。
5. 华为、博世、西门子、美的的 AI/工业软件实习招聘入口。

## 重要现实

当前字节公开职位主要面向 2027 届，你是 2028 届，不能直接把这些岗位等同于当前可投机会。它们更适合作为未来 12 个月的准备标准。应持续关注 2028 届日常实习和下一轮暑期实习。
