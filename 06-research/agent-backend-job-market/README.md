# Agent 与后端岗位市场研究

## 研究目标

研究互联网中大厂和先进制造企业对以下候选人的真实要求：

- Agent 应用/平台开发
- Java 或服务端后端开发
- 能在 AI 辅助下完成前后端完整交付的工程型人才

## 研究问题

1. 目标岗位的职责边界是什么？
2. 哪些能力在不同企业中重复出现？
3. 哪些岗位适合本科实习生，哪些只是用于观察高级岗位能力上限？
4. 当前简历与目标岗位之间有哪些直接匹配和缺口？

## 边界

- 优先使用企业招聘官网，Boss 直聘搜索结果用于补充发现岗位。
- 岗位是否可投以企业官网详情为准。
- 社招和已过期岗位只用于提炼能力模型，不作为当前投递建议。
- 本轮采样日期：2026-07-13。

## 当前结论

最适合的定位不是泛化的“AI 全栈”，而是：

> 以后端与系统工程为根基，能建设 Agent Runtime、工具和评测，并借助 AI 完成前后端闭环交付的工程型开发者。
