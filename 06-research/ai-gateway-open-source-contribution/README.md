# AI Gateway Open Source Contribution

## Research Goal

- 在开源 AI gateway 项目里选一个成熟、适合外部贡献的仓库。
- 目标不是只看热度，而是找到一个可以较快切入并提交有效代码的项目。

## Scope

- 包含 4 个候选仓库的对比：`BerriAI/litellm`、`Portkey-AI/gateway`、`QuantumNous/new-api`、`songquanpeng/one-api`。
- 包含 issue 规模、标签质量、release 节奏、是否存在新贡献者入口的比较。
- 包含一个可重复运行的 issue 导出脚本和首批候选 issue。
- 不包含深入源码实现细节。
- 不包含本轮直接写 PR。

## Research Questions

- 核心问题 1：哪个 gateway 项目既成熟，又不会让第一次贡献被超大 issue 池淹没？
- 核心问题 2：哪些仓库对外部贡献者最友好，能较快找到边界清晰的任务？
- 核心问题 3：第一批值得尝试的 issue 应该从哪几类问题切入？

## Current Status

- 阶段：Repository selection and issue scouting
- 最近一次更新：2026-06-16

## Expected Output

- 选出 1 个优先仓库。
- 给出 2 到 3 个最适合起手的 issue 方向。
- 留下可复用的 issue 抓取方法，便于后续继续筛选。
