# China AI Industry 2026-2046

## Research Goal

- 研究 2026—2046 年中国经济与产业结构可能如何变化，以及 AI 在其中扮演的是通用生产技术、资本品、基础设施，还是独立产业。
- 把宏观趋势转化为计算机学生在 Agent 与后端开发方向上的职业判断。

## Scope

- 包含：中国人口与就业、宏观增长约束、产业政策、AI 成本与能力、制造业与服务业重构、能源与算力、软件岗位变化。
- 时间分为 2026—2030、2031—2035、2036—2046 三段。
- 采用基准、加速、受阻三种情景，不给出单点式“准确预测”。
- 不包含：个股和具体投资建议、单一公司的商业预测、战争等极端事件的精确概率。

## Research Questions

1. 中国未来 20 年最稳定的产业驱动因素与约束是什么？
2. AI 成本下降和任务能力提高，会先重构哪些产业、企业和工作任务？
3. 哪些产业的增长来自真实需求，哪些更多依赖政策、资本开支或短期叙事？
4. 初级程序员、后端工程师和 Agent 工程师分别会发生什么变化？
5. 计算机学生现在应建立哪些抗商品化能力？

## Current Status

- 阶段：第一轮综合（Synthesis v0.1）
- 最近一次更新：2026-07-11
- 置信度：近五年方向中等偏高；2031—2035 中等；2036—2046 低到中等。

## Expected Output

- 一套“慢变量—技术—政策—产业—岗位”的证据框架。
- 一张未来产业地图和三个时间阶段的情景判断。
- 一份面向 Agent / 后端求职的技能与项目路线。
