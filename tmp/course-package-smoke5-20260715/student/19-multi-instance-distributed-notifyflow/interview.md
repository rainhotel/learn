# 第 19 章面试追问

## 分布式锁和 lease 有什么区别？

lease 有期限和续约语义，但旧 owner 可能恢复；需要单调 fencing token 让下游拒绝陈旧写。仅有锁 key 不足以防僵尸 owner。

## 如何避免重复消费？

至少一次消费后，使用 eventId/业务键唯一约束、Inbox、状态机和幂等副作用；offset 只是进度，不替代业务幂等。

## 为什么不能承诺 exactly-once？

消息系统、数据库和外部 Provider 跨系统无法靠一个事务覆盖。应明确传输语义和业务效果一致性机制。

## 多实例限流怎么做？

集中计数、令牌租赁或网关全局控制；说明一致性/可用性、时钟、网络和副本变化。下游配额还需本地快速保护。

## 扩容消费者为什么可能变差？

下游 Provider/DB 容量未增加，更多消费者会增加并发、重试、连接和限流错误，形成恢复风暴。

## Agent 能自动释放 lease 吗？

不能默认执行。它可以指出异常 owner 和证据；强制释放要验证 token、状态、审批和审计，避免双 owner。
