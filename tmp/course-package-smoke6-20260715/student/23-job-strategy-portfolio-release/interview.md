# 第 23 章面试追问

## 为什么同时投 Java 和 Agent 后端？

主语言和工程底座统一为 Java；Agent 后端是在可靠 API、数据、消息、观测和安全之上增加模型、检索与 Tool Runtime。根据岗位调整证据顺序，不声称自己精通所有语言。

## 为什么选择先进制造？

制造数字化重视集成、权限、可追溯任务、数据正确性和长期运维，与 NotifyFlow 的可靠任务和事故分析证据相邻。但具体岗位仍要以实时 JD 和业务场景核验。

## 你的项目是生产项目吗？

NotifyFlow 是独立工程与课程项目。回答时逐项区分已运行实验、确定性模型、设计初稿和 Pending；不把它描述为大烨线上系统。

## 为什么没有写 10 万 QPS？

没有对应环境、负载脚本、原始输出和正确性报告。容量数字只有在固定版本和硬件下运行后才可写，并同时说明瓶颈和边界。

## 课程为什么可以售卖？

当前还不能称为正式 Released。达到发布条件需要实验、作业、评分、Teach-back、陌生读者、版权和版本门禁都通过；现阶段定位为内部 Alpha。

## 投递没有反馈怎么办？

先检查岗位时效和硬门槛，再按批次审视目标、摘要和证据，不根据少量样本频繁重写全部路线。无法归因时继续采样，不虚构结论。
