## 单题评分

| 维度 | 分值 |
|---|---:|
| 结论准确 | 2 |
| 机制完整 | 2 |
| 场景与失败模式 | 2 |
| 项目证据 | 2 |
| 边界、替代与表达 | 2 |

没有机制或证据的流畅背诵不得超过 5 分；虚构经历或数字该题计 0 分并进入事实审计。
