# 第 18 章练习

1. 把一个“自动重放失败通知”的需求拆成确定性工作流和 Agent 可选步骤。
2. 为只读查询、创建 preview 和执行 replay 写三份 Tool 合同。
3. 设计 Tool timeout 后的 UNKNOWN 对账流程。
4. 设计 run/event/attempt/approval 数据模型和唯一约束。
5. 说明会话 context、working memory、long-term memory 与业务状态的差异。
6. 设计 prompt injection、跨租户检索和恶意工具返回攻击用例。
7. 设计 Agent 最大步骤、token、成本、工具次数和墙钟预算。
8. 比较工作流、单 Agent 和多 Agent 的评测方案。
9. 设计 SSE 断线重连、取消和最终状态持久化。
10. 设计崩溃恢复和多实例租约，避免重复工具副作用。
11. 写一次高风险工具人工审批的审计时间线。
12. 写一段不夸大效果的 Agent 项目简历描述。
