# 第 13 章 Teach-back

## 5 分钟

只讲需求、峰值 QPS、主链路、状态真相和最大风险，不展开所有中间件。

## 15 分钟

加入 API 幂等、状态机、Outbox、消费幂等、UNKNOWN、容量与观测，并回答三个故障追问。

## 45 分钟

完成正式设计评审：需求澄清、计算、架构、数据、时序、可靠性、多实例、观测、安全、Agent、成本、演进和证据边界。

## 验收

- 不堆组件，每个组件都对应需求和失败模式。
- 所有数字写明公式、输入与误差。
- 能从正常链路切换到重复、乱序、超时和部分失败。
- 能说明个人贡献与未验证边界。
- 记录评审者追问，并在下一版设计中回应。
