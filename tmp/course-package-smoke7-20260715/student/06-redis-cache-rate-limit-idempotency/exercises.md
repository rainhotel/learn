# 章节练习

总分 100 分。实验和故障题必须至少取得 60%，总分达到 80 才进入项目答辩。

## A. 数据结构与 key（15 分）

1. 为模板缓存、滑动窗口限流、临时去重、任务进度分别选择数据结构并说明原因。（8 分）
2. 为什么 key 要包含租户和版本？Cluster hash tag 有什么收益与风险？（7 分）

## B. 原子性与事务（20 分）

1. 单命令、`MULTI/EXEC`、`WATCH`、Lua 分别解决什么问题？（8 分）
2. Redis 事务为什么不等同于 MySQL 事务？（4 分）
3. `INCR` 后再 `EXPIRE` 有什么竞态？用 Lua 修复。（8 分）

## C. 缓存工程（20 分）

1. 写出 Cache Aside 的读写流程。（4 分）
2. 数据库更新后删除缓存仍有哪些竞态和失败路径？（6 分）
3. 区分穿透、击穿和雪崩，并各给出两个治理措施。（6 分）
4. 为什么高命中率不能证明缓存健康？（4 分）

## D. 限流与幂等（20 分）

1. 固定窗口为什么会在边界突发？（4 分）
2. 比较固定窗口、滑动窗口日志和令牌桶。（6 分）
3. Redis 幂等 key 被淘汰后如何保持正确性？（5 分）
4. Agent 设备控制工具在 Redis 故障时应该 fail-open 还是 fail-closed？说明决策依据。（5 分）

## E. 高可用、锁与排障（25 分）

1. 为什么异步复制和 `WAIT` 仍不能保证零丢写？（5 分）
2. Sentinel 的 quorum 和多数授权有什么区别？（4 分）
3. Cluster 的 16384 slot、hash tag 和写安全边界是什么？（5 分）
4. 为什么锁 value 必须唯一，释放时必须比较 owner？（4 分）
5. fencing token 解决什么问题？（3 分）
6. 线上 P99 突然升高，列出 Redis 排查顺序。（4 分）

## 必做实验

1. 复现 `INCR`/`EXPIRE` 泄漏并用 Lua 修复。
2. 对比无保护与 single-flight 缓存击穿。
3. 配置小 `maxmemory`，观察 eviction 导致幂等 key 消失，验证数据库唯一约束兜底。
4. 构造锁过期后旧持有者恢复，使用 fencing token 拒绝旧写。
5. 生成大 key，观察命令延迟并使用 `--bigkeys`/`--memkeys` 定位。

提交物：代码、配置、完整命令、RED/GREEN 或故障/恢复输出、指标截图数据和复盘。

## 加分题

- 构造一主两从加三 Sentinel，测量故障检测、选举、重连和数据缺口时间线。（10 分）
- 建立三主三从 Cluster，演示 slot、hash tag、MOVED 重定向与节点故障。（10 分）
