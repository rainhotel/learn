# Teach-back 试讲

## 5 分钟版本

1. 任务表是事实状态和并发协调的基础。
2. 聚簇/二级索引、回表、联合索引。
3. EXPLAIN ANALYZE 验证实际访问路径。
4. RR 快照读和 FOR UPDATE 领取的区别。
5. 短事务领取 + lease/version + 事务外副作用。

## 15 分钟版本

### 0-3 分钟：需求

多实例发送通知、重复请求、重启恢复和供应商慢调用。

### 3-7 分钟：索引

展示 50,000 条数据上复合索引前后执行计划，解释覆盖与回表。

### 7-11 分钟：事务

讲 MVCC、RR/RC、锁定读、SKIP LOCKED 和短事务。

### 11-13 分钟：租约与幂等

讲 worker、lease_until、version、唯一约束和外部幂等。

### 13-15 分钟：死锁

展示一个事务被 1213 回滚，说明重试完整事务。

## 必画图

```text
二级索引 -> 主键 -> 聚簇记录（回表）

领取事务 -> 提交 -> 外部发送 -> 条件回写
```
