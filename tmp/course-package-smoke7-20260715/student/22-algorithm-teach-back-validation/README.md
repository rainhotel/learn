# 第 22 章：Java 算法、Teach-back 与学习验证

## 章节定位

- 类型：Algorithm Interview + Deliberate Practice + Teach-back + Evidence Validation
- 难度：基础到深入
- 建议学习时间：80-120 小时，分布在 8-10 周
- 先修要求：Java 语法、集合框架、递归、单元测试基础
- 对应目标：Java 后端与 Agent 工程岗位的编码面试、现场推理和教学输出

## 当前状态

- 阶段：八件套完整内容初稿，训练与验证 Pending
- 课程题量：规划 96 个“首次解题槽位”，不是已完成题量
- 已完成：知识地图、题量配额、Java 模板、间隔复习、白板编码、测试、Teach-back、陌生读者测试和模拟面试规则
- 未完成：个人基线测评、96 题训练、复习到期记录、录像、陌生读者反馈和模拟面试成绩

没有原始提交、复习记录、测试输出和第三方反馈前，本章不能标记为 Lab Verified、Release Candidate 或 Released。

## 为什么不是“背 100 道答案”

大厂算法面试同时考察：问题澄清、数据结构选择、复杂度、正确性论证、边界测试、可运行 Java 代码和沟通。记住题解只能产生熟悉感，无法证明在无提示条件下完成迁移。

本章使用六层证据链：

```text
首次独立求解
-> 可运行测试
-> 复杂度与正确性解释
-> 1/3/7/14/30 天间隔复习
-> 白板/共享编辑器编码
-> Teach-back、陌生读者测试与模拟面试
```

## 核心问题

1. 如何在 80-100 题范围内覆盖高频结构，又避免随机刷题？
2. 如何把题目识别为不变量、状态、边、窗口或搜索空间，而不是背题名？
3. Java 中如何安全使用数组、哈希表、栈、队列、堆、树、图和并查集？
4. 如何推导时间、空间复杂度，并识别隐藏的字符串复制、装箱和递归栈成本？
5. 如何在没有 IDE 补全的条件下写出可编译代码？
6. 如何为 null、空集、单元素、重复值、溢出、环和极端规模设计测试？
7. 如何用间隔复习区分“看懂了”和“能重新做出”？
8. 如何通过 Teach-back 暴露概念跳步和模板依赖？
9. 如何让陌生读者和模拟面试官验证表达，而不是自我感觉良好？
10. 如何形成可用于简历、面试和课程交付的诚实学习证据？

## 学习成果

完成并通过验证后，学习者能够：

- 为 96 个训练槽位维护来源、首次解法、错误类型、测试和复习历史。
- 从约束推导数组、哈希、双指针、滑动窗口、栈、队列、堆、树、图、回溯、动态规划或贪心方案。
- 在 Java 21 中写出边界明确、命名清晰、复杂度合理且可测试的代码。
- 用循环不变量、归纳、交换论证或状态定义解释为什么算法正确。
- 在 35-45 分钟内完成澄清、朴素解、优化、编码、测试和复杂度分析。
- 对典型模板完成 5/15/30 分钟 Teach-back，并根据陌生读者反馈修订讲义。
- 区分训练目标、已完成记录、复习通过和模拟面试表现，不虚构题量或成绩。

## 96 题课程配额

| 模块 | 目标槽位 | 核心能力 |
|---|---:|---|
| 数组、字符串、排序基础 | 12 | 遍历、不变量、原地修改、计数 |
| 哈希、前缀和、双指针、滑动窗口 | 16 | 空间换时间、区间状态、去重 |
| 链表、栈、队列、单调结构 | 10 | 指针重连、模拟、最近未决元素 |
| 二分搜索与答案二分 | 8 | 单调性、边界收缩、溢出安全 |
| 二叉树、BST、Trie、堆 | 14 | 递归语义、层序、Top K、优先级 |
| 图、拓扑排序、并查集、最短路 | 10 | 建图、访问状态、依赖与连通性 |
| 回溯与搜索剪枝 | 8 | 决策树、选择/撤销、去重 |
| 动态规划 | 12 | 状态、转移、初始化、遍历顺序 |
| 贪心、区间与综合设计 | 6 | 局部选择证明、边界组合 |
| 合计 | 96 | 处于 80-100 题目标区间 |

题目可以按个人短板替换，但每次替换必须保持模块配额和难度结构，并记录原因。相同题目的复习不重复计入 96 个首次解题槽位。

## 建议节奏

- 第 0 周：三题基线测评，建立证据目录，不据此宣称能力等级。
- 第 1-2 周：数组、字符串、哈希、前缀和、双指针与窗口。
- 第 3 周：链表、栈、队列、单调结构与二分。
- 第 4-5 周：树、BST、Trie、堆。
- 第 6 周：图、拓扑排序、并查集与最短路。
- 第 7-8 周：回溯、动态规划、贪心和综合题。
- 第 9 周：到期复习、白板编码、陌生读者测试。
- 第 10 周：三轮模拟面试、错因复盘和求职证据整理。

若复习债务持续增长，应减少新题，而不是为了题量跳过复习。

## 退出标准

- 96 个首次解题槽位均有可追溯证据，且不存在以复习重复充数。
- 核心模板能在无补全环境中写出并通过自建边界测试。
- 到期复习按计划执行；未通过项有下一次日期和错因，不用“看过”标记通过。
- 能对至少六类算法给出正确性解释，而不只复述代码。
- 三轮模拟面试均保留原始题目、录像或逐字记录、测试结果和评审反馈。
- 陌生读者只依赖讲义即可完成指定任务，失败点已进入修订记录。
- 所有对外题量、正确率和成绩均能回指证据；没有证据时只写 Pending。
