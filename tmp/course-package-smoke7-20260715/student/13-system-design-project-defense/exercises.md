# 第 13 章练习

1. 为 NotifyFlow 写一页需求、假设、SLO、范围与非目标。
2. 估算日任务 1000 万、峰值系数 8、平均扇出 2.5 时的峰值创建与投递 QPS。
3. 设计创建任务 API 的幂等合同、错误码和查询接口。
4. 画任务、attempt、Outbox、回调和 UNKNOWN 对账状态机。
5. 说明 MySQL、Redis、Kafka 各自保存什么，谁是最终事实来源。
6. 设计消费者崩溃、Provider timeout、回调乱序和重复重放的恢复路径。
7. 给出多租户配额、背压、降级、优雅下线和恢复风暴控制方案。
8. 写出 SLI、告警、低基数指标、日志字段、Trace 和正确性查询。
9. 对事故助手完成 Tool 权限、证据引用、prompt injection 和审批边界设计。
10. 写五条 ADR，分别说明当前选择、替代方案、代价和触发重构的条件。
11. 完成 15 分钟项目答辩录音，并根据追问修订设计。
12. 区分实习事实、独立项目实现、设计方案和 Pending 实验，写成简历安全表述。
