## 核心问题

1. 如何从 Java 后端、Agent 后端和先进制造岗位中确定主攻与备选？
2. 如何采样 JD，而不是被单条岗位或技术热词带偏？
3. 如何把关键词映射到课程章节、项目任务和证据？
4. 如何维护事实主简历，而不是复制十份互相矛盾的简历？
5. 如何设计小批次投递、反馈指标和修订节奏？
6. 如何把课程文档整理为可购买、可学习、可验证的产品？
7. 哪些条件满足后才能称为 Release Candidate 或 Released？

## 退出标准

- 建立至少三类岗位的采样表和去重规则。
- 每个目标 JD 都有匹配分、缺口、投递版本和证据链接。
- 维护一份事实主简历及三种岗位摘要。
- 能根据面试反馈定位到具体章节、练习和实验。
- 建立课程目录、学习者手册、样章、勘误、版本和版权清单。
- 完成陌生读者测试，并保留问题与修订记录。
- 不使用未经实时核验的岗位数量、薪资或企业排名结论。
