# 第 14 章面试追问

## Attention 为什么需要 mask？

自回归生成不能看到未来 token，否则训练目标泄漏；causal mask 让位置 i 只能访问不晚于 i 的位置。

## KV cache 解决什么问题？

decode 每生成一个 token 时复用历史 K/V，减少重复计算；代价是随层数、上下文、KV heads 和并发增长的显存占用。

## RAG 为什么会幻觉？

检索未命中、chunk 不完整、权限/版本过滤错误、context 太长、模型忽略证据或引用映射错误都可能发生。要看检索和生成两段证据。

## 向量检索和 BM25 如何选？

语义改写适合向量，精确编号/错误码/专有名词适合关键词；真实系统通常做混合召回、过滤和 rerank，再用评测集比较。

## Agent 和工作流区别？

工作流的步骤和分支由代码确定；Agent 可以在边界内选择下一步，但工具合同、状态机、权限、预算和停止条件仍由代码控制。

## 如何防止 Tool 重复副作用？

使用幂等键、业务唯一约束、状态机、超时 UNKNOWN、查询/对账和审计；模型重试不能直接创建第二次副作用。

## Java 后端如何做流式模型响应？

使用 SSE/响应式流处理 backpressure、客户端断开、心跳、取消、超时和最终状态持久化；token 流不能绕过内容安全和结构化校验。

## Agent 能否直接操作 Kubernetes？

默认不能。它可以读脱敏状态并生成建议；扩容、回滚、删除、重放和 Secret 访问必须经过 RBAC、审批、审计和 kill switch。
