# 第 18 章参考答案与评分

## 核心答案

- Agent 负责受限选择，确定性 Runtime 负责权限、状态、预算和执行。
- timeout 可能产生 UNKNOWN，有副作用工具不能普通重试；用查询/回调/对账收敛。
- Memory 不能替代业务数据库，摘要必须引用原始事件。
- 高风险 Tool 至少需要 preview、审批、幂等、速率、审计、kill switch 和恢复。
- 多 Agent 必须与工作流/单 Agent 基线比较成本、延迟和错误。

## 评分

| 维度 | 分值 |
|---|---:|
| Agent 状态机与预算 | 20 |
| Tool 合同与可靠执行 | 25 |
| Memory/状态分层 | 15 |
| 安全与人工审批 | 20 |
| Java/SSE/恢复 | 15 |
| 诚实表达 | 5 |

允许模型直接执行高风险动作、没有幂等/UNKNOWN/审计的设计不得超过 50 分。
