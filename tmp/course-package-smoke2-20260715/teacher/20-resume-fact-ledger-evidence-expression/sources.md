## 二、岗位与技能分类来源

1. O*NET OnLine：<https://www.onetonline.org/>
2. Occupational Outlook Handbook, Software Developers：<https://www.bls.gov/ooh/computer-and-information-technology/software-developers.htm>
3. 中国国家职业分类大典（人力资源和社会保障部）：<https://www.mohrss.gov.cn/>

O*NET/BLS 可用于理解职业任务和技能维度，但中国当期岗位要求必须以带日期的真实 JD 和企业招聘官网为准。不得用职业分类页面冒充实时岗位频次、薪资或招聘数量。

1. 中华人民共和国个人信息保护法（中国人大网）：<http://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html>

这些来源用于提醒个人信息、密钥和敏感材料风险；涉及公司保密、知识产权和具体法律争议时，应遵守合同、公司政策并咨询合格专业人士。

## 四、ATS 与关键词来源边界

- 不引用“保证通过 ATS”的营销结论。
- 不假设所有 ATS 解析规则相同。
- ATS 关键词必须来自保存了原文、链接和日期的目标 JD。
- PDF 是否可解析应通过实际文本提取检查，不以肉眼版式代替。
- 隐藏文字、虚假关键词和与经历无关的技能属于高风险做法。

## 五、证据使用规则

1. 官方职业和求职资料只能支持一般写作原则，不能证明学习者个人事实。
2. 个人 claim 必须由事实台账、原始材料和可复核工程证据证明。
3. Git 提交只能证明某账户提交内容，不能单独证明业务影响、独立完成或生产上线。
4. 运行截图只能证明某个时刻的界面，必须补环境、版本、命令和原始输出。
5. 推荐信、证明和他人确认不能替代对技术细节的本人理解。
6. AI 生成的简历文本属于证据等级 1，不能创造事实。
