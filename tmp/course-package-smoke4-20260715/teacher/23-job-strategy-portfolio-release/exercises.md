# 第 23 章练习

1. 为 Java 后端、Agent 后端、先进制造各写一份岗位采样标准。
2. 从五条已核验 JD 中提取字段、去重并区分必需与加分项。
3. 为一条 JD 完成 100 分匹配表和 veto 检查。
4. 将十个 JD 关键词映射到章节、项目任务和证据。
5. 从事实主简历生成三种摘要，验证事实和时间完全一致。
6. 设计两批小规模投递实验，明确唯一主要变量。
7. 把一次模拟或真实面试反馈回写为章节练习和复习任务。
8. 建立 NotifyFlow 作品集目录和 evidence index。
9. 对课程做一次版权、隐私、链接、版本和答案隔离检查。
10. 邀请陌生读者完成一个样章，记录用时、阻塞点和错误理解。
11. 写 Release Candidate 决策记录，列出通过、失败和 Pending 项。
12. 写一段不承诺 offer、薪资或命中率的诚实课程介绍。
