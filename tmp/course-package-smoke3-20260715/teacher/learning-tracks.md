# 学习路线与学时合同

## 1. 为什么拆成两条路线

23 章建议学时合计远高于一个暑假的 200-250 小时。课程因此分为：

- 10 周求职核心版：在有限时间内形成 Java 后端主线、一个可靠项目故事和基本 Agent 工程认知。
- 完整进阶版：完成全部章节、核心实验、RAG/Agent、分布式和教学发布验证。

核心版不是“十周精通全部 23 章”。未进入核心版的章节保留为选修或后续进阶，不能在销售页暗示十周全部完成。

## 2. 10 周求职核心版

时间合同：每周 20-25 小时，总计 200-250 小时。算法每天另安排 30-45 分钟，已计入周预算。

| 周 | 核心章节 | 目标 | 周预算 |
|---|---|---|---:|
| 0 | 基线、20 | 环境、事实台账、Java/算法基线 | 10-15h 预备 |
| 1 | 01、03 | 线程池、JMM、并发正确性 | 20-25h |
| 2 | 04、05 | MySQL、事务、Spring 代理边界 | 20-25h |
| 3 | 06 | Redis 缓存、限流、短期幂等 | 20-25h |
| 4 | 07 | Kafka、消费语义与 Outbox | 20-25h |
| 5 | 08 | 重试、DLT、UNKNOWN 与对账 | 20-25h |
| 6 | 09、10 选读 | 可观测性、压测、JFR 与 JVM 排障 | 20-25h |
| 7 | 11、12 选读 | 网络超时、连接池、Docker/K8s 入门 | 20-25h |
| 8 | 14、15-17 选读 | LLM/RAG 原理与一条最小评测链 | 20-25h |
| 9 | 18 | Tool、Memory、权限与可靠 Agent Runtime | 20-25h |
| 10 | 13、20-23 | 项目答辩、简历、模拟面试和投递准备 | 20-25h |

“选读”表示只完成核心问题、一个最小实验或设计，不宣称达到该章完整退出标准。

### 核心版必须完成

- 第 01、03-09、18、20-21 章的核心作业。
- NotifyFlow 最小纵切：任务创建、持久化、Outbox/事件、消费、Provider stub、UNKNOWN/对账和指标。
- 一个 RAG/Agent 最小纵切：固定小语料、检索、引用、拒答和只读 Tool 边界。
- 至少一次真实组件故障实验、一份数据正确性报告和一份项目答辩录像。
- 一份事实简历和一轮陌生评审模拟面试。

### 核心版明确不承诺

- 完成全部 23 章完整学时。
- 完成 96 道算法题；十周只要求按第 22 章记录稳定周节奏。
- 掌握生产级 Kubernetes、多机分布式或大模型推理优化。
- 获得 offer、特定薪资或命中企业题库。

## 3. 完整进阶版

建议周期：24-32 周，每周 18-25 小时；或按学习者已有基础重新估算。目标是达到 560-756 小时章节总学时中的大部分，并完成真实验证。

| 阶段 | 章节 | 建议周期 | 出口证据 |
|---|---|---:|---|
| Java 与数据基础 | 01-05 | 4-6 周 | JDK/MySQL/Spring 实验与 Teach-back |
| 可靠后端 | 06-09 | 4-5 周 | Redis/Kafka/恢复/压测故障证据 |
| 生产与平台 | 10-13 | 4-5 周 | JVM、网络、容器、K8s 与系统设计评审 |
| RAG 与 Agent | 14-18 | 5-7 周 | ingestion、检索、评测、安全和 Runtime 证据 |
| 多机分布式 | 19 | 2-3 周 | 多实例、lease/fencing、故障恢复证据 |
| 求职与发布 | 20-23 | 3-6 周并行 | 简历、算法、模拟面试、JD、陌生读者和发布审计 |

完整进阶版只有在各阶段实验和学习验证通过后，才能使用“完成课程”表述。

## 4. 三种学习者入口

### Java 基础薄弱

先完成 01-05，不并行 RAG。算法从数组、链表、哈希和树开始；Spring/Maven 环境阻塞时先做 JDK 与 SQL 实验。

### 已有 Java 后端基础

先做闭卷基线；01-05 达到 80% 可压缩，但必须保留至少一个并发和一个事务证据。重点投入 06-13 与项目纵切。

### 已有后端、转 Agent 工程

先验证 05、07-09、11 的可靠性基础，再进入 14-18。不能跳过权限、幂等、超时、评测和数据正确性，只学习 Prompt 或框架 API。

## 5. 完成度表达

学习记录必须使用下列之一：

- 已阅读：完成讲义和问题地图。
- 已练习：完成作业，但未运行实验。
- 已验证：按固定环境运行并保存证据。
- 已教学验证：完成陌生听众 Teach-back 并修订。

“参加十周核心版”不等于“完成 23 章完整进阶版”。
