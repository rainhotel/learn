## 静态验证

使用 Node.js 对三个 ES module 脚本执行语法检查：

```powershell
node --check lab\k6\open-load.js
node --check lab\k6\closed-load.js
node --check lab\k6\recovery-stages.js
```

结果：三个命令均退出码 0。Node.js 只验证 JavaScript 语法，不验证 k6 executor、threshold 或 HTTP 运行行为。

静态语义审阅修正了两个关键问题：

- 不再使用连续 ramp 冒充分档稳定运行。
- 不再用 GET probe 请求率冒充恢复速率；脚本改为实验专用、每次最多处理 1 条的 drain 接口，并为错误率、P99、dropped iteration 和 checks 配置 `abortOnFail`。
- 修正 Gauge threshold：当前值使用 Gauge，峰值使用 Trend 的 `max` 聚合。
- 用每请求 contract Rate 替代可能被多个 check 稀释的全局 checks threshold；客户端和恢复 probe 时延也不再冒充 provider 或 backlog drain 时延。
